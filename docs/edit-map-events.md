## 1. 背景

「修改」新增两个二级分类：**地图**、**公共事件**。参考 MTool 的同名页面，但不照搬它的展示：

| MTool 的问题                                                       | 本方案                                               |
| ------------------------------------------------------------------ | ---------------------------------------------------- |
| 地图树用 `┣` `┃` 字符画，层级深、只有名字，顶部下拉框与树重复      | 可折叠树 + 「当前地图 / 最近去过」快捷入口，带事件数 |
| 「传送至 0,0」常落在墙里或图外                                     | 传送落点可选：入口、指定坐标、迷你地图点选           |
| 事件只显示 `Pos` / `Page 0` / `事件长度`，看不出是什么、有没有出现 | 事件表：推断类型 + 一句话状态                        |
| 「切换全部条件 / 全部独立开关」一键改整张图，无说明、不可撤销      | 按事件、按条件逐条操作；改状态前自动快照，可撤销     |
| 公共事件平铺、`1__` 补位、`0127` 补零，每行重复「事件解释器」按钮  | 列表 + 详情；触发方式、开关、运行状态、引用关系可见  |
| 迷你地图、解释器是独立弹窗                                         | 内嵌在页面里，链接互跳                               |

## 2. 两页共用

### 2.1 数据来源

| 内容                     | 静态（不开游戏）               | 运行时（游戏在线）                                             |
| ------------------------ | ------------------------------ | -------------------------------------------------------------- |
| 地图树                   | `data/MapInfos.json`           | `$dataMapInfos`                                                |
| 地图事件、页、条件、指令 | `data/MapXXX.json`             | 仅当前地图在 `$dataMap`；实时位置 / 当前页 `$gameMap.events()` |
| 公共事件                 | `data/CommonEvents.json`       | `$dataCommonEvents`；并行事件运行状态 `$gameMap._commonEvents` |
| 开关 / 变量 / 独立开关   | 名称来自 `data/System.json`    | `$gameSwitches` / `$gameVariables` / `$gameSelfSwitches`       |
| 当前位置                 | —                              | `$gameMap.mapId()`、`$gamePlayer.x/y`                          |
| 译名                     | 现有翻译库查表（原文悬停可见） | 同左                                                           |

静态数据 local 由服务读盘，edge 由浏览器授权读，游戏内用 XHR 读 `data/*.json`（与引擎加载方式一致，兼容打包游戏）；三处走同一份解析。MZ 无 `www/` 目录，路径按现有游戏根目录解析规则处理。

### 2.2 事件索引

每个游戏读一次全部地图、公共事件、敌群（`Troops.json`），建一份索引并缓存（按数据文件 mtime / 大小判定失效后重建；游戏内按会话缓存）。大型游戏地图可达数百张，读取需并发受限并显示进度，读取失败的地图跳过并计数，不阻塞整页：

- **入口**：所有「场所移动」（201）的目标地图与坐标 → 地图页的传送落点。
- **调用**：所有「调用公共事件」（117）→ 公共事件页的「被谁调用」。
- **事件类型**：按触发方式、指令内容、行走图推断：对话、战斗、传送点、宝箱、商店、自动剧情、并行处理、其他。
- **副作用摘要**：一段指令会改什么（开关、变量、金钱、物品、队伍、传送、战斗、游戏结束、存档）。

### 2.3 事件解释器

把指令列表渲染成可读剧本，两页共用一个组件：

- 对话（101 / 401）显示说话人与译文；选项（102）、条件分支（111）、循环用缩进表示层级，可折叠。
- 开关 / 变量操作显示名称而不只是编号，如「开关 #12『进入地下水路』= 打开」。
- 「场所移动」链接到地图页对应地图；「调用公共事件」链接到公共事件页。
- 插件指令（MV 356 / MZ 357）显示原始参数，不做解释。
- 未知指令显示指令码与参数，不报错。

### 2.4 安全

- 撤销（第 3 期起）：改状态的操作执行前自动快照，页头提供「撤销上一步」。快照只覆盖可精确还原的状态：开关、变量、独立开关、玩家地图与坐标。执行事件的其余副作用（物品、金钱、角色、对话进度、战斗等）不承诺撤销，确认框写明「执行后无法完全撤销」。第 1、2 期不显示撤销按钮。
- 需确认的操作：
  - 执行带高风险副作用（战斗、游戏结束、存档、传送）的事件，确认框列出副作用摘要。
  - 批量操作（第 3 期：事件表多选后批量切换独立开关 / 满足条件），确认框列出受影响事件。
  - 迷你地图点选传送（防误点）。
- 不需确认：从「入口」「指定坐标」传送（目标已明确展示）、单个独立开关切换。
- 操作结果用 toast 反馈；失败显示游戏返回的原因（如「请回到地图场景」）。局内浮层执行事件 / 传送后自动收起面板，让玩家看到效果。
- 游戏未在线：全部可浏览，操作按钮置灰并提示「启动游戏后可用」。
- Agent 边界不变：Agent 只经 `chaya_edit_action`（`teleport`、`common_event`）等预设能力操作，不获得逐字段改写能力。

## 3. 地图

### 3.1 布局（宽屏）

```text
┌ 修改 › 地图 ─────────────────────────────────── [搜索地图 / 事件] [撤销] ┐
│ ┌ 地图 ─────────────┐ ┌ 住宅地 · #3 · 40×30 ─────────────────────────┐ │
│ │ 当前：住宅地       │ │ 地下水路 › 住宅地                            │ │
│ │ 最近：卢米娜之家…  │ │ [传送到这里 ▾]   入口：从地下水路进入 (12,5)  │ │
│ │ ───────────────   │ ├───────────────────────┬──────────────────────┤ │
│ │ ▾ 住宅地      12  │ │ 迷你地图              │ 事件 [全部|对话|传送点|宝箱|未出现] │
│ │   ▸ 卢米娜之家 8  │ │  · · ● · · ·          │ 名称     类型   位置  状态        │
│ │   ▸ 杂货店     3  │ │  · ◆ · · @ ·          │ 史莱姆1  战斗   0,7   出现中      │
│ │ ▸ 地下水路    21  │ │  · · · ▣ · ·          │ 宝箱     宝箱   5,3   已触发 (A)  │
│ └───────────────────┘ └───────────────────────┴──────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

### 3.2 左栏：找地图

- 顶部固定「当前地图」「最近去过」。「最近去过」由 ChayaEdit 自己记录地图切换（最多 10 张，按游戏持久化），不依赖 Agent 是否启用；游戏未在线时显示上次记录，无记录则隐藏。
- 可折叠树；选中当前地图时自动展开祖先并滚动到位。每项右侧显示事件数，可筛「隐藏空地图」。
- 名称以译名为主，悬停显示原名。搜索匹配编号、译名、原名、事件名；命中事件时跳到所在地图并高亮该事件。

### 3.3 右栏：地图

- **地图信息**：名称、编号、尺寸、祖先路径（面包屑）。
- **传送到这里**（主操作，下拉选落点）：
  - 入口：来自事件索引（§2.2），列出「从哪张图、哪个事件进入，落在哪」。无入口的地图（如开场地图）不显示此项。
  - 指定坐标：手动输入 x、y，按地图尺寸校验越界。
  - 迷你地图点选（第 3 期）：点空格子传送，需确认。
- **迷你地图**（第 3 期；之前事件表占满右栏）：网格 + 玩家 + 事件点（按类型区分图标与颜色）。点事件点选中事件。先不画图块；第 4 期按图块通行设置画墙 / 路，当前地图可用截图做底图。
- **事件表**：名称、类型（§2.2）、位置、状态、操作（传送到旁边、立即触发、详情）。
  - 状态一句话：出现中 / 未出现（条件不满足）/ 已触发（独立开关 A 打开）。
  - 非当前地图：独立开关可读写；「出现中 / 未出现」按条件推算，标注为推算。
  - 游戏未在线：状态列显示「—」（开关、独立开关都是存档数据，离线不可知），只展示类型与位置。
  - 传送到旁边：落地后在游戏内按通行判断选事件四邻中可走的一格，都不可走则落在事件格本身。
  - 立即触发：仅当前地图可用（`$gameMap.event(id).start()`）；非当前地图置灰并提示先传送过去。

### 3.4 事件详情（右侧抽屉）

- 按页分标签，标出当前生效页（当前地图取实时页，其余地图为推算，离线不标）。
- 出现条件写成中文，每条标是否满足。开关、变量、独立开关条件附「满足此条件」按钮；持有物品、角色在队等条件只展示，不提供一键满足（会改动背包 / 队伍，交给对应修改分类）。
- 「满足此条件」改的开关 / 变量若还被其他事件引用，按钮旁提示引用数，确认框列出受影响事件。
- 独立开关 A / B / C / D 四个开关，只作用于本事件；离线时显示「—」且不可切换。
- 触发方式（确定键、接触、自动执行、并行处理）与移动设置简述。
- 事件内容：解释器（§2.3）。

## 4. 公共事件

### 4.1 布局（宽屏）

```text
┌ 修改 › 公共事件 ──────────── [全部|手动|自动执行|并行] [搜索名称 / 内容] [撤销] ┐
│ ┌ 列表 ─────────────────────────────┐ ┌ #12 改名为西尔菲娜 ─────────────────┐ │
│ │ 系统                              │ │ 手动调用 · 28 条指令                │ │
│ │  1  游戏初始化        自动 · #1 ✓ │ │ [执行]                              │ │
│ │  5  全回复            手动        │ │ 会修改：角色名、开关 #20            │ │
│ │ 变身                              │ │ 被调用：住宅地 › 卢米娜 (第 2 页)   │ │
│ │ 12  改名为西尔菲娜    手动        │ │        公共事件 #13 变身为西尔芬行动 │ │
│ │ 13  变身为西尔芬行动  手动        │ │ 调用：公共事件 #3 删除所有图像       │ │
│ │ 19  #日常立绘         并行 · 运行中│ ├─────────────────────────────────────┤ │
│ │ …                                 │ │ 内容（解释器）                      │ │
│ └───────────────────────────────────┘ └─────────────────────────────────────┘ │
└───────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 列表

- 每行：编号、译名（悬停原名）、触发方式标签。不显示补位 `__` 与补零长度；指令条数放详情。
- 自动执行 / 并行事件附触发开关与当前状态：`#1 ✓`（开关已开）、「运行中」（并行事件正在跑）。
- 默认隐藏空事件（无名且无指令；结尾的空指令不计），可切换显示。
- 分组：作者常用无指令的名字做分隔（如 `----`、`■系统`、`◆变身`），识别为分组标题，可折叠；识别不到时平铺。
- 筛选：全部 / 手动 / 自动执行 / 并行；另可筛「未被任何地方调用」（只看手动事件，自动执行 / 并行本就不靠调用；地图未扫描完整时提示结果可能偏多）。
- 自动执行 / 并行的触发开关状态、「运行中」需游戏在线；离线只显示触发方式与开关编号。
- 搜索两种：名称（默认）与内容（对话文本、开关 / 变量名），后者用于「这句台词在哪个事件里」。

### 4.3 详情

- **头部**：名称、编号、触发方式、指令条数。
- **执行**：仅手动事件显示主按钮。需在地图场景（`$gameTemp.reserveCommonEvent`，即现有 `Cheats.runCommonEvent`）；不在地图时置灰并说明。含高风险副作用时确认框列出摘要。
- **自动执行 / 并行**：不提供「执行」，改为显示触发开关并可切换（打开即开始、关闭即停止），切换需确认。确认框提示：该开关被其他事件共用时一并生效；自动执行事件若自身不关闭开关会持续锁住操作，需回到此处关闭。
- **会修改**：副作用摘要（§2.2），执行前判断风险。
- **引用关系**：被哪些地图事件 / 公共事件 / 敌群调用，它又调用了哪些；地图事件与公共事件条目可点（地图页上线前，地图事件条目只展示），敌群条目只展示（无敌群页）。
- **内容**：解释器（§2.3）。

## 5. 窄屏（局内浮层）

游戏窗口常见 816×624，不分栏，改为逐层进入，顶部面包屑返回：

- 地图：地图列表 → 地图详情（迷你地图、事件表上下排）→ 事件详情。
- 公共事件：列表 → 详情。

宽窄屏用同一套组件（`components/game-edit`），只换外壳。

## 6. 分期

1. 事件索引、解释器、公共事件页：列表 / 筛选 / 名称搜索、详情、引用关系、手动事件执行、自动执行 / 并行的触发开关切换。内容搜索与「运行中」状态顺延到第 2 期；edge 模式未连接游戏时第 1 期提示「连接游戏后可浏览」，浏览器授权读盘在第 2 期补上。
2. 地图页：地图树（含最近去过）、地图信息、事件表、传送落点（入口 / 指定坐标）、事件详情；公共事件页的地图事件引用改为可跳转。
3. 迷你地图、快照撤销、批量操作（事件表多选：批量切独立开关 / 满足条件）。
4. 迷你地图图块 / 截图底图。
