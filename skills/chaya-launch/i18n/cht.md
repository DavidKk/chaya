# Chaya：添加游戏与啟動

## 1. 添加游戏

- **App / 本地 dev**：控制台「游戏库」→ 選擇游戏。可选 `www` 目錄、含 `www` 的发布目錄，或 NW.js 包（macOS `.app` / Windows `Game.exe` 所在目錄）。Chaya 会识别 MV / MZ 內容根并加入游戏库。
- **Edge**：在 Chrome / Edge 中選擇含 `www` 或 `index.html` 的目錄并授权读写。
- 游戏库支持备注、切换、移除（只移除记录，不删游戏文件）。

## 2. 装壳（NW.js）

RPG Maker 游戏需要 NW.js 執行。Chaya 使用统一的壳：

- 游戏库详情里点「安裝壳」，默认从 nwjs.io 下載目前平台最新稳定版（约 100 MB）。已自带壳的打包游戏无需安裝。
- **macOS 壳无法啟動**：結束游戏后在終端機執行下面的命令，按 6 步进度提示選擇游戏目錄，看到「✓ 安裝完成」后双击 `Chaya.app`：

  ```bash
  /bin/bash -c "$(curl -fsSL https://chaya-gray.vercel.app/sh/mac-shell.sh)"
  ```

  存档会保留，旧壳自动備份。

## 3. 外掛程式

啟動游戏时 Chaya 会自动注入外掛程式；也可以在游戏库手动「安裝 / 清除外掛程式」。

| 外掛程式      | 作用                                                                       |
| ------------- | -------------------------------------------------------------------------- |
| `ChayaLoader` | 薄加载器：从本机 Chaya 拉取外掛程式，离线时回退到磁盘缓存                  |
| `ChayaLog`    | 外掛程式執行时与日志上报                                                   |
| `ChayaTrans`  | 局内翻译：预翻译缓存 / 本地模型实时翻译 / 字幕                             |
| `ChayaBoost`  | 移动加速：`ChayaBoost.on()` / `off()`                                      |
| `ChayaEdit`   | 局内修改：金钱、物品、变量、开关、角色、传送、存读档（`ChayaEdit.help()`） |
| `ChayaAgent`  | Agent 桥：本机 MCP 通过它控制游戏                                          |

更新外掛程式后需重启游戏；已安裝过的旧游戏需要重新安裝一次外掛程式才会加载新外掛程式。

## 4. 啟動与关闭

- **App / 本地 dev**：游戏库点「啟動」。Chaya 会写入啟動配置（含本次的啟動 token）并打开游戏；控制台与游戏通过 WebRTC 直连，顶栏显示在线状态。
- 关闭：控制台点「关闭游戏」，或直接关游戏窗口。
- **Edge**：網頁写好外掛程式与壳后，在本机双击游戏目錄旁的 `Chaya.app` / `Chaya` 啟動。

## 5. 修改（/cheat）

游戏在线时进入「修改」页：改金钱、物品 / 武器 / 防具数量、变量、开关、角色属性，开启无敌、穿墙、加速，传送与存读档。也可在游戏内按快捷键打开同一套修改面板。

## 6. 翻译（/translate）

1. **抽取**：从游戏 data 抽取原文，生成 seed。
2. **补译**：开启整作补译任务，按引擎顺序（默认 Ollama → Bing → Google）补全缺词；可随时暂停。
3. **翻译库**：浏览、搜索、修改、刪除、导入共享译文（所有游戏共用）。
4. **游戏内翻译方式**：预翻译（只用缓存）、实时（本地模型翻对话）、字幕。

## 7. 日志（/logs）

外掛程式与服务的日志集中在「日志」页，可按来源和级别筛选；外掛程式异常、翻译失敗、连接问题先看这里。

## 排查

| 现象                 | 檢查                                                      |
| -------------------- | --------------------------------------------------------- |
| 啟動报「尚未安裝壳」 | 先安裝壳                                                  |
| 外掛程式没生效       | 重新安裝外掛程式并重启游戏；看日志里 `ChayaLoader` 的报错 |
| 控制台显示游戏离线   | 确认游戏是从 Chaya 啟動的；刷新控制台页面                 |
| macOS 游戏打不开     | 執行上面的 macOS 壳修复命令                               |
