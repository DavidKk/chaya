# Chaya: подготовка и запуск игры

## Подготовка

1. **local** (App / разработка): в библиотеке выбрать `www`, содержащую его папку релиза или пакет macOS `.app` / Windows `Game.exe`. Корень MV / MZ определяется автоматически. Удаление из библиотеки убирает только запись.
2. **cloud**: разрешить чтение и запись папки с `www` или `index.html` в Chrome / Microsoft Edge.
3. Установить общую оболочку NW.js из сведений библиотеки (около 100 МБ); если игра содержит собственную, дополнительная не нужна.
4. Установить плагины и перезапускать игру после каждого обновления. Локальный запуск также внедряет их автоматически.

Если оболочка macOS не открывается, закрыть игру, выполнить команду в Терминале, выбрать папку по подсказкам и открыть `Chaya.app`. Сохранения остаются, старая оболочка резервируется:

```bash
/bin/bash -c "$(curl -fsSL https://chaya-gray.vercel.app/sh/mac-shell.sh)"
```

## Плагины и работа

`ChayaLoader` загружает с автономным кешем; `ChayaLog` ведёт журнал; `ChayaTrans` переводит; `ChayaBoost` меняет скорость (`on()` / `off()`); `ChayaEdit` изменяет, телепортирует и сохраняет / загружает (`help()`); `ChayaAgent` связывает управление игрой.

- **local**: Библиотека → Запустить записывает настройки сеанса и открывает игру. Плагин подключается к локальному сервису, консоль показывает состояние.
- **cloud**: после подготовки открыть `Chaya.app` / `Chaya` рядом с папкой игры. Связь использует WebRTC; страница не запускает процессы.
- Изменения (`/cheat`): деньги, предметы, переменные, переключатели, персонажи, неуязвимость, проход сквозь стены, скорость, телепорт, сохранение / загрузка. Игровая клавиша открывает ту же панель.
- Перевод (`/translate`): извлечь seed → запустить дополнение всей игры с включёнными движками и настройками планировщика; доступна пауза. Просмотр, поиск, правка, удаление и импорт кеша. Режимы: предварительный, реального времени, субтитры. Задачи Cloud исполняет подключённая игра; локальная общая библиотека требует local.
- Журналы (`/logs`): фильтровать по источнику и уровню. Выход через консоль или закрытие окна. Перед выходом за пользователя, разрушительными изменениями, очисткой плагинов, перезаписью сохранений или загрузкой получить согласие.

## Неполадки

Недостающую оболочку установить. Если плагины не действуют, переустановить, перезапустить и проверить `ChayaLoader`. При отсутствии связи проверить загрузку `ChayaAgent` и настройки подключения, затем обновить консоль. В macOS при необходимости использовать команду восстановления выше.
