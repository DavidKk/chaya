# Chaya：ゲームの追加と起動

## 1. ゲームを追加

- **App / ローカル dev**：コンソール「ゲームライブラリ」→ ゲームを選択。`www` フォルダー、`www` を含む配布フォルダー、NW.js パッケージ（macOS の `.app` / Windows の `Game.exe` があるフォルダー）を選べます。Chaya が MV / MZ のコンテンツルートを判別してライブラリに追加します。
- **Edge**：Chrome / Edge で `www` か `index.html` を含むフォルダーを選び、読み書きを許可します。
- ライブラリではメモ、切り替え、削除ができます（削除は記録だけで、ゲームファイルは消しません）。

## 2. シェル（NW.js）の導入

RPG Maker のゲームは NW.js で動きます。Chaya は共通のシェルを使います：

- ライブラリの詳細で「シェルを導入」を押すと、既定で nwjs.io からこのプラットフォームの最新安定版（約 100 MB）をダウンロードします。シェル同梱のパッケージ済みゲームは不要です。
- **macOS でシェルが起動しない**：ゲームを終了し、ターミナルで次のコマンドを実行します。6 ステップの案内に従ってゲームフォルダーを選び、「✓ インストール完了」が出たら `Chaya.app` をダブルクリック：

  ```bash
  /bin/bash -c "$(curl -fsSL https://chaya-gray.vercel.app/sh/mac-shell.sh)"
  ```

  セーブデータは残り、古いシェルは自動でバックアップされます。

## 3. プラグイン

ゲーム起動時に Chaya が自動でプラグインを注入します。ライブラリで手動で「プラグインを導入 / 消去」もできます。

| プラグイン    | 役割                                                                                                      |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| `ChayaLoader` | 薄いローダー：ローカルの Chaya からプラグインを取得し、オフライン時はディスクキャッシュを使用             |
| `ChayaLog`    | プラグインのランタイムとログ送信                                                                          |
| `ChayaTrans`  | ゲーム内翻訳：事前翻訳キャッシュ / ローカルモデルのリアルタイム翻訳 / 字幕                                |
| `ChayaBoost`  | 移動高速化：`ChayaBoost.on()` / `off()`                                                                   |
| `ChayaEdit`   | ゲーム内改造：所持金、アイテム、変数、スイッチ、キャラ、テレポート、セーブ / ロード（`ChayaEdit.help()`） |
| `ChayaAgent`  | エージェントブリッジ：ローカル MCP はこれを通してゲームを操作                                             |

プラグインを更新したらゲームを再起動してください。以前導入したゲームは、新しいプラグインを読み込むために一度プラグインを入れ直す必要があります。

## 4. 起動と終了

- **App / ローカル dev**：ライブラリで「起動」。Chaya が起動設定（今回の起動 token を含む）を書き込んでゲームを開きます。コンソールとゲームは WebRTC で直接つながり、上部バーにオンライン状態が表示されます。
- 終了：コンソールで「ゲームを終了」を押すか、ゲームのウィンドウを閉じます。
- **Edge**：ページがプラグインとシェルを書き込んだら、ゲームフォルダー横の `Chaya.app` / `Chaya` をダブルクリックして起動します。

## 5. 改造（/cheat）

ゲームがオンラインのときに「改造」ページで、所持金、アイテム / 武器 / 防具の個数、変数、スイッチ、キャラの能力値を変更し、無敵・壁抜け・高速化、テレポート、セーブ / ロードができます。ゲーム内でもショートカットキーで同じパネルを開けます。

## 6. 翻訳（/translate）

1. **抽出**：ゲーム data から原文を抽出して seed を作ります。
2. **補完**：ゲーム全体の補完翻訳ジョブを開始し、エンジン順（既定 Ollama → Bing → Google）で未翻訳を埋めます。いつでも一時停止できます。
3. **翻訳ライブラリ**：共有訳文（全ゲーム共通）の閲覧、検索、編集、削除、インポート。
4. **ゲーム内翻訳方式**：事前翻訳（キャッシュのみ）、リアルタイム（ローカルモデルで会話を翻訳）、字幕。

## 7. ログ（/logs）

プラグインとサーバーのログは「ログ」ページに集まり、ソースとレベルで絞り込めます。プラグインの異常、翻訳失敗、接続の問題はまずここを確認してください。

## トラブルシューティング

| 症状                               | 確認                                                                      |
| ---------------------------------- | ------------------------------------------------------------------------- |
| 起動時に「シェル未導入」と出る     | 先にシェルを導入                                                          |
| プラグインが効かない               | プラグインを入れ直してゲームを再起動。ログの `ChayaLoader` のエラーを確認 |
| コンソールでゲームがオフライン表示 | Chaya から起動したか確認し、コンソールを再読み込み                        |
| macOS でゲームが開かない           | 上の macOS シェル修復コマンドを実行                                       |
