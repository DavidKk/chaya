# Bergamot 本地离线翻译与语言包管理需求

- 创建日期：2026-10-19
- 更新日期：2026-10-23
- 状态：第一阶段实现与验证中；当前仅开放 macOS Apple Silicon 的英语 → 简体中文自动安装，其它模型／平台和英语中转尚未开放
- 适用范围：Chaya Linux、macOS 本机服务，以及连接该服务的 Web 控制台和游戏内浮层
- 技术设计：[Bergamot 本地离线翻译与语言包管理技术设计](technical/linux-offline-translation.md)

当前验证结果：Bergamot 已跑通应用内下载、进度、校验、独立试译、原子安装、取消／重试及损坏修复，真实下载后可离线翻译。Apple 原生仍只提供系统下载操作指引。完整覆盖目标与发行包验收不能据此视为完成，详见技术文档的本次实施记录。

## 1. 背景与目标

Bergamot 是 Chaya 的本地离线机器翻译引擎。现有代码已接入引擎开关、状态检测、单语向翻译，以及实时翻译和 seed 补译链路；运行时无需 Python、GPU 或用户自行部署模型服务。

目前原生程序和语言模型分开交付。本机调查发现，程序可以正常运行，但当前英语 → 简体中文所需的模型目录不存在，因此返回 `model_pack_missing`。用户无法在应用内补齐模型，现有“设置指引／检查更新”不能形成完整解决路径。

目标：用户选择翻译语言后，只需点击“安装语言包”，Chaya 自动完成下载、校验、配置与加载检测，用户无需查找模型网站、复制文件、修改配置或使用终端。

Bergamot 属于轻量机器翻译工具，与 Agent／本地大语言模型是独立引擎。本需求不调整现有翻译调度、缓存优先规则和其它引擎的开关。

## 2. 交付边界

| 部分               | 责任与用户体验                                                         |
| ------------------ | ---------------------------------------------------------------------- |
| Bergamot 原生程序  | 由 Chaya 构建并随受支持平台的安装包交付，普通用户不安装编译依赖        |
| 离线语言模型       | Chaya 维护经过兼容验证的清单，用户在应用内按需安装                     |
| Apple 原生语言包   | 仍由系统管理，保留系统操作指引，不使用 Bergamot 下载流程               |
| 不支持的系统／架构 | 明确提示不支持，不能把问题展示为缺语言包                               |
| 组件缺失或无法启动 | 说明应用组件异常，提示重启、修复或重新安装，不提供模型安装作为解决办法 |

下载语言包需要联网；安装完成后的翻译在本机执行，文本不因安装或英语中转被发送至下载服务。点击安装只准备模型，不自动开启引擎，也不启动游戏文本翻译任务；安装验证仅使用应用内置的固定测试文本。

Windows 引擎接入、其它离线引擎、大模型安装器、公共模型市场不属于本期范围。平台支持必须以安装包实机验证为准，不能仅依据上游支持情况声明可用。

## 3. 语言覆盖与能力声明

Chaya 的核心语言为英语 `en`、简体中文 `zh`、繁体中文 `cht`、日语 `ja`、韩语 `ko`、法语 `fr`、德语 `de`、西班牙语 `es`、俄语 `ru`、巴西葡萄牙语 `pt-BR`。

2026-10-23 核对 Mozilla 模型注册表（清单生成于 2026-10-22），上述非英语语言均有与英语双向翻译的已发布模型，其中葡萄牙语使用通用 `pt`，不等于专门的巴西葡语模型。其余语言之间没有对应的直接模型，需考虑英语中转。

| 路径                     | 目标行为                                       | 发布条件                                           |
| ------------------------ | ---------------------------------------------- | -------------------------------------------------- |
| 英语 ↔ 其它 9 种核心语言 | 使用对应方向的直接模型，共 18 个方向           | 每个模型及平台完成兼容和质量验收后才进入可安装清单 |
| 两种非英语语言互译       | 优先使用已验证直接模型；无直接模型时经英语中转 | 两段模型及中转流程均通过验证                       |
| 相同语言                 | 无需安装与翻译                                 | 返回“无需翻译”，不得误标缺包                       |
| 没有可用路径             | 显示“不支持当前语言对”                         | 不提供安装按钮                                     |

覆盖全部 90 个跨语言方向是目标，不能以“上游有模型”作为全部已支持的依据。繁体中文必须使用繁体模型；`pt-BR` 使用通用葡萄牙语时需明确说明地域表达可能不同。

## 4. 用户流程

### 4.1 状态检测与安装入口

用户进入翻译页、切换当前语言对或点击“重新检测”时，检查引擎组件、翻译路径和所需语言包。

- 检测中：使用 Badge 专用 loading 样式与“检测中”文字。
- 就绪：显示“已就绪”，允许用户开启引擎。
- 缺语言包且可安装：显示当前语向和“安装语言包”入口，不再要求用户上网寻找文件。
- 尚无经过验证的安装资源：显示“当前版本暂不支持此语言对”，不以“检查更新”冒充可执行的安装操作。
- 不支持或检测失败：说明具体原因；可恢复错误提供重试。

语言包是本机共享资源，多个游戏使用同一模型时不重复下载。当前语向已有可用模型时，升级任务不影响其就绪状态与翻译；升级失败继续使用原可用版本。就绪状态仍针对当前语言对，不能因另一个语言对可用而显示全局就绪。

### 4.2 安装前说明

点击安装入口后，展示当前翻译方向、直接／经英语中转、需要新增的模型列表、总下载大小及预计磁盘占用。已经安装且验证可用的模型标为已安装，不重复计入下载量。

例如日语 → 简体中文缺少两个模型时，展示“需要安装日语 → 英语、英语 → 简体中文；翻译经英语中转，可能更慢并影响准确性”。用户点击“安装”后才开始联网下载。

下载大小来自固定资源清单，禁止使用“约 25MB”等未经核对的固定文案。磁盘占用需考虑解压文件及安装过程的临时空间。

### 4.3 进度与完成

安装期间显示当前阶段、当前模型、已下载／总大小及下载进度条。下载结束后显示“校验中”“安装中”“验证中”，不能把“下载 100%”表示成安装完成。

用户可以取消安装；关闭指引、离开页面或关闭游戏不会取消由本机服务管理的安装任务。再次打开页面可恢复查看进度，执行安装的本机服务退出则中断任务；关闭 Electron 主窗口是否中断，取决于本机服务是否继续运行。服务下次启动时恢复核对已提交的模型，其余工作显示中断状态和重试入口。

全部所需模型安装并加载验证成功后，自动刷新该语向的就绪状态，显示“已就绪，可以开启”。不自动修改用户的引擎开关。

### 4.4 失败与取消

- 网络断开／超时：保留错误说明与重试入口。
- 空间不足／无写入权限：说明原因，用户处理后可重试。
- 校验失败／模型不兼容／加载失败：不得显示已就绪，不发布损坏的语言包。已安装文件损坏时提供“修复语言包”，重新下载和验证，不能因同版本目录已经存在而跳过。
- 中转路径仅部分模型完成：保留已成功安装的模型，重试只安装缺失或失败的部分。
- 重复点击或多个界面安装同一资源：复用任务，不重复下载和覆盖。
- 取消：停止该任务尚未完成的工作，清理未发布的临时文件，保留已有可用模型；若任务被多个界面共用，取消前提示会影响这些界面。已经进入单包提交的工作先完成该次提交，再停止后续工作；若整个任务已完成，取消返回已完成结果，不把成功任务改为已取消。

首版可从头重下未完成文件；若未实现断点续传，不展示“继续下载”或保留进度的承诺。

## 5. 离线翻译与英语中转

有经过验证的直接模型时优先直译；否则仅允许通过英语进行两段本地翻译，不进行无限路径搜索，也不自动转用云端引擎。

两段均成功后才把最终译文交给现有翻译管线。中间英语文本不作为目标语言写入游戏或共享缓存。任何一段失败，整个 Bergamot 请求失败，后续行为沿用现有调度策略。

实时翻译、单条翻译和 seed 补译使用一致的语向解析。占位符、控制码、换行等保护机制必须贯穿两段翻译，不能因中转破坏游戏文本。

首次加载与稳态翻译分别测量；中转需同时评估两段耗时和内存。包大小、峰值内存和时延以实测为准，不承诺所有设备单句 50ms 或内存小于 100MB。

## 6. 交互与权限

控制台和游戏内浮层复用同一套安装状态与组件。所有用户可见文案覆盖现有 10 种界面语言，进度变化可供辅助技术读取，不能仅靠颜色表达阶段。

由当前受信任的本机服务执行安装，资源安装在服务所在设备。远程浏览器不能在浏览器设备上安装原生模型；没有对应管理权限时展示不可安装原因，并提供前往该服务控制台安装的入口，安装后游戏内可重新检测。安装、取消不因页面可读状态而自动获得授权。

HTTP／IPC 使用稳定的英文状态与错误码，前端映射本地化说明。普通用户无需看到模型下载 URL、环境变量或配置文件路径。

## 7. 验收标准

1. 干净的受支持安装环境包含可启动的 Bergamot 程序，不要求用户安装编译工具。
2. 英语 → 简体中文缺包时，用户仅通过应用内操作完成下载、进度查看、安装与验证，最终可开启引擎并得到真实译文。
3. 下载、校验、安装、验证阶段可区分；字节进度真实，未知长度不会伪造百分比。
4. 断网、失败重试、取消、服务重启、重复安装、空间不足及已安装模型损坏均有可恢复反馈；已有可用模型不被破坏。取消与发布并发时，最终状态与磁盘上实际可用模型一致。
5. 切换语言对后状态、安装计划与实际翻译方向一致；游戏内不能固定目标为中文。多个游戏和界面共享同一已安装模型。升级期间旧模型仍就绪。
6. 日语 → 简体中文在两段模型均通过验证后，可一次安装缺失模型并完成英语中转；缺任一段时不显示就绪。
7. 繁体中文不会被当作简体中文；通用葡萄牙语的适配限制明确展示。
8. 不支持的平台、语言对及未验证模型不提供无效安装按钮。
9. 安装完成不自动开启引擎、不自动开始翻译；安装期间其它可用翻译能力不受影响。
10. 已安装模型在断网环境仍可翻译；纯状态查询和翻译请求不会隐式下载模型。无管理权限的游戏内用户可前往控制台完成安装，再回到游戏检测使用。

## 8. 实施顺序

- 第一阶段：固定模型清单、兼容验证、程序打包检查、受管目录与原生读取协议、直接语向安装及真实翻译验证、真实进度、失败／取消／重启恢复、前端入口。
- 第二阶段：两段英语中转、组合安装、共享模型复用及质量／性能验收。

第一阶段只开放实际验证过的语向。第二阶段完成后再逐步开放其它语向，未完成部分明确展示为暂不支持。
