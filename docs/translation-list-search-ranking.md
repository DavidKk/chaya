# 翻译列表多语言搜索与相关度排序需求

- 日期：2026-10-25
- 状态：现行设计（已实现并纳入回归测试）
- 技术设计：[多语言分词排序设计](technical/translation-list-search-ranking.md)。

## 目标与痛点

在 `/translate/list` 翻译管理页面中，支持根据输入的搜索词（如 `q=Rei`）进行高相关度匹配过滤与自然排序。

### 现状痛点

现有检索算法优先使用了 `startsWith(q)`，导致输入独立单词 `Rei` 时，以该前缀开头的长词（如 `reika`、`reiji`、`reinforcement`）排在前面，而包含独立完整单词 `Rei` 的句子或短语被排到后面。

### 核心目标

1. **独立单词/词元匹配优先**：当搜索词与文本中某个完整词元一致时（如 `"Rei"` 命中 `"Rei: Let's go!"`），该项必须排在仅词首前缀匹配（如 `"Reika"`、`"Reiji"`）的前面。
2. **多语言针对性支持**：优先解决三大核心语言：
   - **英语（EN）**：原文主要语言之一，以空格和标点断词。
   - **日语（JA）**：游戏原文主要语言，无空格连写，包含假名、汉字、外来语片假名及罗马字。
   - **中文（ZH）**：目标译文主要语言，无空格连写。
   - 后续可平滑扩展西欧、韩语等多语言。
3. **零外部大字典依赖与高性能**：在纯客户端（10,000 ~ 50,000 条条目）筛选下，按键响应保持在 15ms 内，不引入数兆字节的离线字典包。

## 匹配等级与排序规则

按照匹配紧密度将结果划分为四个等级（Tier 0 ~ Tier 3），数值越小越靠前：

### 1. 匹配等级基准值（Tier）

各等级基准分阶梯跨度为 10，确保等级判定绝对优先于字段权重微调：

- **Tier 0（全字段完全相等，基准值 0）**：去除空白与控制符后，文本与查询词完全相同（如 `Rei` 等于 `Rei`）。
- **Tier 1（独立词元完全匹配 Exact Token Match / 短语首匹配，基准值 10）**：文本分词后的某个独立 Token 与查询词完全相等，或多词短语自句首完全吻合。
  - 单词例：`q="Rei"`，文本 `"Sword of Rei"` 或 `"Rei: 待って"` 切出独立词 `"Rei"`，判定为 Tier 1。
  - 短语例：`q="save game"`，文本 `"Save game here"` 自首部完整匹配短语，判定为 Tier 1。
- **Tier 2（词元前缀匹配 Token Prefix Match / 词组边界匹配，基准值 20）**：某个独立 Token 以查询词开头（但词长大于查询词），或句首以此短语开头，或空格短语位于词边界。
  - 前缀例：`q="Rei"`，文本 `"Reika"` 或 `"Reiji"` 判定为 Tier 2。
  - 同为 Tier 2 时，词元长度越短越靠前（`Reika` 优于 `Reinforcement`）。
- **Tier 3（普通子串包含 Substring Match，基准值 30）**：查询词仅作为子串出现在词元内部（非词边界）。
  - 例：`q="Rei"`，文本 `"Foreign"` 或 `"キレイ"`。

### 2. 字段权重（Field Weight）

多字段搜索时保留信息重要度梯度：

- 原文（`src`）：`+0.0`（权重最高）
- 译文（`zh` / `savedZh` / `initialZh`）：`+1.0`
- 词条键与标识（`meta.localesKey`）：`+2.0`
- 词条序号（`id`）：`+3.0`
- 其他元信息（`meta.speaker` / `context` / `label` / `file`）：`+4.0`

综合得分：
$$\text{Rank} = \text{Tier} + \text{FieldWeight} + \text{PrefixLengthPenalty} + \text{PositionPenalty}$$

- **跨等级绝对优先**：各 Tier 基准值相隔 10，而字段权重最大偏移为 +4.0，因此任何高等级匹配（如 Tier 1 最弱字段得分 14.0）必然排在低等级匹配（如 Tier 2 最优字段得分 20.0）之前。
- **PrefixLengthPenalty**：$\min(\Delta \text{len} \times 0.1, 5.0)$，词元越接近查询词长度惩罚越小。
- **PositionPenalty**：$\min(\text{pos} \times 0.005, 0.5)$，命中位置越靠前微调越靠前。

### 3. 次级决胜（Tie-breaker）

当两条记录综合得分相同时：

1. **字符串总长度更短优先**：同样命中独立词，较短的短句/词条排在超长对白之前。
2. **命中位置更靠前优先**：词元出现在句首优于句尾。
3. **主键稳定排序**：`item.id` 字典序。

## 验收标准

1. **英文词素验收**：
   - 搜索 `abc` 时，包含独立单词 `abc` 的条目必须排在 `abcd`、`abcde` 之前。
   - 搜索 `Rei` 时，`Rei` 和 `Rei: Let's go!` 必须排在 `reika`、`reiji` 之前。
2. **日文分词验收**：
   - 搜索 `レイ` 时，`レイの剣`（切出独立词「レイ」）必须排在 `レイカ` 之前。
3. **中文分词验收**：
   - 搜索 `确认` 时，`待确认` 必须排在仅单字偶发分散匹配的句子之前。
4. **性能与兼容性验收**：
   - 全量 20,000 条数据检索过滤耗时小于 15ms。
   - 兼容全角/半角输入（NFKC 标准化）。
