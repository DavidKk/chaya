# lib

未配置的基础抽象：类型、纯算法、可复用工具。不读写项目配置、不连第三方、不持有进程内全局状态。

| 目录       | 内容                                    |
| ---------- | --------------------------------------- |
| `utils.ts` | UI `cn` 等                              |
| `log/`     | 日志级别 / 条目类型、规范化             |
| `game/`    | 游戏路径解析算法、常量、插件清单解析    |
| `plugin/`  | 插件控制台样式等（改编自 MagickMonkey） |

具体服务见 [`services/`](../services/)。游戏内插件见根目录 [`plugins/`](../plugins/)。
