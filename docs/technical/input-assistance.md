# 输入辅助技术文档

> 以当前「辅助 > 键鼠」页面及实现为准，更新于 2026-10-07。用户行为见 [需求文档](../input-assistance.md)。

## 结构

| 职责                                     | 代码位置                                                                                           |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 辅助导航与三组行内编辑                   | `app/assist/`、`components/input-assistance/`                                                      |
| 局内浮层「辅助」外壳与直连通道           | `components/settings/GameEditAgentSettingsPane.tsx`、`plugins/src/cheat/ui/game-tool-transport.ts` |
| 规则类型、校验、合并、冲突提示和录制摘要 | `lib/game/input-assistance/`                                                                       |
| 全局配置 API                             | `app/api/input-assistance/global/route.ts`                                                         |
| 游戏侧配置、命令和持久化                 | `plugins/src/cheat/input-assistance/controller.ts`                                                 |
| 游戏侧触发路由、回放和输入释放           | `plugins/src/cheat/input-assistance/runtime.ts`                                                    |
| 网页与游戏消息                           | `lib/runtime/game-link-protocol.ts`                                                                |

网页负责录制与编辑；不要求连接游戏。连接后通过 GameLink 同步全局和本游戏配置并接收状态。游戏插件独立安装运行时，负责识别物理输入、执行规则和释放输出，页面卸载不销毁运行时。全局配置在桌面服务中写入 `data/input-assistance/global.json`；浏览器模式使用 localStorage。本游戏配置优先写入游戏内容目录的 `chaya/config/input-assistance.json`，无文件系统时退回游戏 localStorage；网页还缓存本游戏快照。

页面通过 `GameToolTransportContext` 取通道：Web 控制台由 `GameLinkProvider` 提供 GameLink 通道（edge 即浏览器模式，通用配置存 localStorage）；局内浮层由插件提供直连通道，命令直接交给控制器，通用配置存游戏 localStorage。控制器区分 GameLink 客户端与浮层：浮层不占用 GameLink 的状态回传；浮层保存后向已连接的网页推送 `assist.config`。两端连接或收到推送时都按 `revision` 采用较新的一份并写回本端存储，较旧的一端再把自己的新版本下发。

## 规则与页面

规则有 `turbo`、`macro`、`mapping` 三种 `kind`，分别显示为「键鼠连发」「键鼠动作」「键鼠映射」。每条规则有稳定 `id`、`enabled`、`trigger` 和 `originalInput`。当前 UI 默认把原键设为 `replace`，不提供切换；规则名称仅用于内部和冲突提示，不作为编辑字段。新规则默认 `enabled: true`，运行时只匹配通过 `validateRule` 的完整规则。

`InputChord` 是键盘或鼠标输入数组，按物理键 `code`/位置或鼠标按钮识别。映射的 `output` 是同时保持的组合；连发的 `output` 恰好一个输入，`interval` 为固定值或 `[minMs, maxMs]` 范围；动作的 `events` 是带 `atMs`、`down/up` 的时序列表。摘要只负责展示，运行时使用结构化事件。动作当前从 UI 建立为单次回放，`repeat.enabled` 默认为 `false`；底层保留重复和独立停止键字段，但页面没有相应控件。

录制器在网页文档捕获键鼠事件，任何游戏连接状态下均可使用。同一时间仅有一个录制会话。录制器只收玩家真实输入（`isTrusted`），连发、动作和 Agent 发出的合成按键不会录入；开始录制时游戏内运行时停止所有正在运行的规则，录制期间不启动新规则，但松开按键时的映射清理照常执行。连发输出只取单个输入；映射输出可录多个输入；动作保留完整按下/松开时序，最多 20 步、80 个事件。`spaceMacroEvents` 保证相邻非同步步骤至少间隔 17 ms、按住至少 24 ms，最多相差 2 ms 的按下视为同时发生。完成录制前需松开输入；修改动作和间隔通过重录，不单独编辑步骤。快捷键字段单独录入组合，允许左、中、右鼠标键。

全局与本游戏规则按 `id` 合并，本游戏规则覆盖同 ID 的全局规则。保存前校验结构、版本、大小和有效间隔；空触发或空输出允许作为草稿持久化，但不进入运行态。冲突提示比较同一绑定和长短组合重叠，允许保存。快捷键都是全局生效的，因此键鼠工具与快捷键页双向互标：两边都化成「修饰键 + 主键」集合（Meta 记为 Ctrl，数字与字母按物理键位），键鼠触发键全部落在快捷键里即算冲突（键鼠规则按「已按下的键包含触发键」触发，Chaya 快捷键要求修饰键完全一致，所以只有这一方向会同时触发）。键鼠页拿当前生效、未暂停的 Chaya 快捷键（含固定的 Agent 面板 `Ctrl+Shift+A`）标在触发键上；快捷键页拿已启用且可运行（非草稿）规则的触发键与独立停止键，标在提供生效绑定的那一格（有本游戏绑定标本游戏格，否则标全局格）。页面顶部搜索仅过滤渲染结果，分组开关计算并修改整组有效规则，不让搜索结果改变批量操作的范围。

## 游戏侧执行

运行时在游戏文档的捕获阶段监听可信物理键鼠输入，跳过文本输入和插件面板。组合键在最后一个成员按下时匹配；较长匹配优先。被替换的原键事件会被阻止，生成的事件带内部标记，不再作为辅助触发。映射在触发键按住时持有输出，松开后释放；连发按快捷键切换启停，每次点按按下时间至多 24 ms，下一次间隔从配置范围取值；动作按事件时间轴回放一次。输出持有表按规则引用计数，停止时释放本规则持有的输入。

鼠标输出以游戏画布坐标换算。RPG Maker `TouchInput` 可接收左键，以及支持 `_onCancel` 时的右键；中键或其他无法确认的路径会报错。普通 DOM 合成事件无法变成可信事件，目标游戏是否接收仍须在具体游戏验证。运行中的规则在失焦、隐藏、停止、配置重载或插件卸载时停止。Agent 获得输入控制时通过游戏侧停止入口结束辅助规则。

## 同步与限制

GameLink 命令含 `gameId` 与请求 ID；游戏侧校验游戏身份并缓存近期回复，防止重复执行。配置带版本和 `revision`；服务端全局保存检查预期版本，连接时比较快照版本。状态只传运行规则、待切回游戏规则、次数、录制状态和错误。页面离线可编辑，已运行规则由游戏插件继续运行；网页断连后不自动重启已停止规则。网页发出的启动命令在游戏失焦时最多等待 15 秒，恢复焦点后执行。

当前页面没有循环宏、单独停止键、保留原键、位置策略和测试按钮；相关类型或 GameLink 命令仅表示底层预留能力。输入适配仍以当前游戏实际接收情况为限，尤其不能把右键、中键或浏览器保留快捷键视为跨游戏保证。
