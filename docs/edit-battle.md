## 1. 背景

战斗中能做的事分散在三处：

- “运行”页“战斗”卡片：胜利、逃跑、失败、中止，以及敌方 / 我方全体 HP 动作。
- “敌群”页顶部“当前战斗”区块：逐个改敌人的 HP、杀死、复活、复制、替换、追加。
- “角色”页：改角色 HP / MP，但它面向角色的长期数据（等级、能力值、装备），不是这一场战斗。

玩家在战斗中要来回切页，而且看不到敌我双方的对照。“敌群”页本来是查看敌群数据、开战的地方，把当前战斗放在它顶部也让列表变挤。

## 2. 目标

| 目标 | 玩家可感知的结果                                                                   |
| ---- | ---------------------------------------------------------------------------------- |
| G1   | 战斗中打开一个页面，就能看到并修改这场战斗的敌方、我方与战斗流程。                 |
| G2   | 敌方、我方用同样的表格与输入框样式，列对齐，一眼可比较。                           |
| G3   | 不在战斗时页面说明原因，并能一步去“敌群”开战。                                     |
| G4   | 与“角色”页分工清楚：战斗页只改这一场战斗里的即时数值，角色的长期数据仍在角色页改。 |

不做（本期）：状态（中毒、增益等）的增删、行动顺序调整、我方移除队员 / 与候补换位、战斗中更换装备。

## 3. 入口与位置

- **二级分类**：“修改”新增**战斗**，路径 `/cheat/battle`，放在“运行”之后（第二位）；网页与局内浮层一致。
- **始终显示**：不在战斗中也显示该分类，内容为空状态（§7），避免二级导航随战斗进出时有时无。
- **战斗中提示**：战斗进行时在该分类上显示小圆点；不自动切换页面，避免打断正在进行的操作。
- **“运行”页**：原“战斗”卡片整体迁到战斗页（§4.1）；“运行”页原位置只留一行“打开战斗页”的链接，替代现有的“管理场上敌人”。
- **“敌群”页**：移除“当前战斗”区块。开战成功后的提示里附“去战斗页”链接（未做）。

## 4. 页面结构

宽屏自上而下三块，区块之间用分割线：

```
┌ 战斗 ─────────────────────────────────────────────────────────────┐
│ 战斗流程   [胜利] [逃跑] [失败] [中止]                               │
├───────────────────────────────────────────────────────────────────┤
│ 敌方                                   [全体 HP 1] [全体回满] [＋]   │
│ 敌人          HP              状态     操作                         │
│ 史莱姆 A      [ 40 / 120 ]    正常     ☠ 复制 替换                   │
│ 史莱姆 B      [  0 / 120 ]    已倒下   ♥ 复制 替换                   │
├───────────────────────────────────────────────────────────────────┤
│ 我方                              [全体回满] [全体 HP 1] [全体 HP 0] │
│ 角色    HP              MP            TP     状态     操作           │
│ 哈罗德  [ 210 / 320 ]   [ 40 / 60 ]   [ 12 ]  正常     ☠ 回满        │
│ 特蕾丝  [   0 / 280 ]   [ 30 / 90 ]   [  0 ]  已倒下   ♥ 回满        │
└───────────────────────────────────────────────────────────────────┘
```

### 4.1 战斗流程

- 放在页面标题栏右侧，五个图标按钮（悬停显示名称）：胜利、逃跑、失败、中止、结算胜负（一方已全灭却仍停在战斗中时立即判定胜负，此时按钮高亮；不在战斗中不做任何事），行为与现有运行动作 `battle:victory / escape / defeat / abort` 相同，只是换了位置。
- 战斗已在结算时按钮禁用并说明原因。

### 4.2 敌方

- 即现有“当前战斗”表格整体迁入，规则不变：见 [edit-troops.md §8](./edit-troops.md#8-战斗中改敌人)。
- 列：敌人、HP（当前 / 上限，同一输入框，两者都可改）、状态、操作（杀死或复活、回满、复制、替换，图标 + 提示；回满即 HP / MP 回满，倒下的先复活）。
- 区块标题栏右侧：全体 HP 设为 1、全体回满（原运行动作 `battle:enemyHp1 / enemyHpMax`），追加敌人。

### 4.3 我方

- 行为出战成员（战斗中的队伍），顺序与游戏战斗画面一致。
- 列：
  - **角色**：名字；点击跳到“角色”页该角色。
  - **HP**：当前 / 上限，同一输入框，两者都可改。当前 0 到上限；改为 0 等同倒下。
  - **MP**：当前 / 上限，同一输入框，两者都可改。
  - **TP**：单个输入框，0 到游戏的 TP 上限（通常 100）。游戏关闭了 TP 显示时仍可改，但列头加提示。
  - **状态**：正常 / 已倒下。
  - **操作**：倒下（存活时）或复活（倒下时）、回满（HP / MP 回满，倒下的先复活）。
- 区块标题栏右侧：全体回满、全体 HP 设为 1、全体 HP 设为 0（原运行动作 `battle:partyHeal / partyHp1 / partyHp0`），以及“追加队友”（＋）。
- **追加队友**：从不在队伍里的角色中搜索选择（候补也算在队伍里，不列出），等同事件指令“更改队伍成员”；出战人数已满（通常 4）时禁用。新队友从下一回合开始行动。
- **锁死**：角色页对 HP / MP 开了锁死时，对应输入框禁用，提示“已在角色页锁死”，并带跳转；锁死开关只在角色页。
- **无敌**：运行页开了“无敌”时，改 HP 为 0 或“倒下”会被游戏立刻恢复；此时“倒下”禁用并提示原因。

### 4.4 输入与反馈

- 所有数字输入：回车或移开焦点生效，Esc 取消；方向键步进不逐次发送。
- 成功 / 失败统一 toast，文案与敌方现有操作一致（如“已复活「哈罗德」”）。
- 场上状态推送有延迟：敌人若已变化（被替换、下标变了），拒绝并提示“场上敌人已变化，请重试”。我方按角色编号定位，队员换位不影响；角色已不在出战成员中时，该行随下一次推送消失。

## 5. 与“角色”页的分工

| 内容                           | 战斗页           | 角色页       |
| ------------------------------ | ---------------- | ------------ |
| 当前 HP / MP / TP、倒下 / 复活 | 可改             | HP / MP 可改 |
| HP / MP 上限                   | 可改（即时生效） | 可改         |
| 等级、能力值、装备、技能       | 不显示           | 可改         |
| 锁死                           | 只显示           | 开关         |

两页改的是同一份游戏数据，任何一边修改，另一边随状态推送刷新。

## 6. 前置条件

- 只在战斗场景内可操作；场景切换中、战斗已结算时禁用并说明原因。
- 网页未连接游戏时整页只读，提示“连接游戏后可用”。

## 7. 空状态（不在战斗中）

- 标题“当前不在战斗中”，说明“开始一场战斗后，这里显示敌我双方并可直接修改”。
- 一个“去敌群开战”链接（跳 `/cheat/troop`）。
- 不显示战斗流程按钮与表格。

## 8. 窄屏（局内浮层）

- 三块纵向堆叠；表格列宽收紧，HP / MP 输入框保持“当前 / 上限”同框。
- 宽度不足时我方表隐藏“状态”列，状态改为名字后的浅色文字（未做；目前横向滚动）。

## 9. 分期

1. **新页 + 迁移**：新增“战斗”分类与空状态；迁入敌方表与战斗流程；“运行”页卡片改为链接；“敌群”页移除当前战斗区块。
2. **我方表**：HP / MP（当前与上限）、TP、倒下 / 复活、回满；全体动作；锁死与无敌的禁用提示。
3. **以后视需要**：状态增删、行动顺序。

## 10. 验收标准

1. 不在战斗时，“战斗”分类可见，显示空状态与“去敌群开战”链接。
2. 进入战斗后，分类出现小圆点；打开后敌我双方表格列对齐，数值与游戏一致。
3. 战斗流程四个按钮行为与原“运行”页一致；“运行”页只剩链接；“敌群”页不再有当前战斗区块。
4. 敌方表全部操作与迁移前一致（见 edit-troops.md §12 第 9、10 条）。
5. 我方改 HP / MP / TP 后，游戏战斗画面的状态窗口立即刷新；当前 HP 改为 0 时角色倒下；复活后角色可再次输入指令。
6. 角色页锁死 HP 时，战斗页 HP 输入框禁用并提示；无敌开启时“倒下”禁用。
7. 队员在战斗中换位后，修改仍作用于正确的角色；被事件移出队伍后，该行消失。
