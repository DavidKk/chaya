# 输入辅助需求

> 当前页面和交互为准，更新于 2026-10-07。实现细节见 [技术文档](technical/input-assistance.md)。

## 目标与入口

玩家在「辅助 > 键鼠」配置输入规则，在游戏中用快捷键触发。设置规则不要求启动或连接游戏。辅助导航还包含快捷键、迷你地图、Agent 和陪玩 AI；键鼠规则与已有产品快捷键分别配置。

页面采用靠左的三张配置卡片，每张卡片含标题、简短说明、添加按钮和规则列表。列表一行一条规则，直接编辑，不要求填写名称或进入弹窗。页面顶部可筛选规则；筛选只改变显示内容，分组开关始终作用于该组全部规则。每条规则可启用、禁用、删除；运行中的规则可停止。新规则默认启用，但字段未录完整时不会在游戏中触发。

## 三组规则

| 分组     | 一行中的配置                                 | 游戏中的行为                                                                                         |
| -------- | -------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 键鼠连发 | 录制一个输出键或鼠标键、输入间隔、设置快捷键 | 按一次快捷键开始重复点按，再按一次停止。输出录制后快捷键默认跟随输出；玩家单独修改快捷键后不再跟随。 |
| 键鼠动作 | 录制按顺序发生的键盘、鼠标动作，设置快捷键   | 每次触发回放一次录制动作。可包含同时按下的组合和先后按下的步骤。                                     |
| 键鼠映射 | 录制输出键鼠组合，设置触发快捷键             | 按住触发键期间保持输出，松开后释放。                                                                 |

连发间隔允许固定数值，例如 `100` ms，或范围，例如 `100-130` ms；范围内每次随机取值，允许范围为 30–2000 ms。动作录制保留按下与松开的时序；摘要显示按键顺序，悬停可查看时间轴。动作步骤和间隔目前通过重新录制修改，不提供单步编辑。录制框主体开始录制，右侧录制图标完成录制；快捷键字段聚焦后录入单键、组合键或鼠标键，清除按钮可移除绑定。

## 配置与反馈

- 支持全局规则和本游戏规则；本游戏中相同 ID 的规则覆盖全局规则。未连接游戏时新建全局规则，已选择游戏时新建本游戏规则。
- 规则冲突只给 warning，允许继续保存和触发。未配置完整的规则允许保存和启用，但运行时忽略，不吞掉玩家原键。
- 游戏连接后页面显示运行次数、待切回游戏执行和执行错误。失焦、切换游戏或插件卸载时停止并释放辅助输入。
- 配置持久化，运行状态不恢复。配置页面关闭后，已在游戏中运行的规则由游戏侧继续管理。

## 当前边界

页面尚无循环动作、独立停止键、保留原键、鼠标位置策略或“测试一次”的编辑控件。它们即使出现在底层规则结构中，也不应在页面说明中作为已交付功能。游戏是否接收合成键盘事件或特定鼠标按钮取决于目标游戏；无法确认时应显示错误，不能声称动作已成功。
