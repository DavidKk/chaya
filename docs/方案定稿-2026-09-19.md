# Chaya 方案定稿（会议纪要续）

- **日期**：2026-09-19
- **状态**：已确认，可按此实现 MVP

---

## 1. 产品形态

- **本地运行**的工具（不以公网网页管本机游戏为主）
- **Next.js**：同一项目含 **Node（API/服务端）+ Client（界面）**
- UI：**Tailwind CSS + shadcn/ui**
- 浏览器打开 `http://127.0.0.1:xxxx` 使用

---

## 2. 与游戏的关系

```text
外部 Windows 游戏（不复制大资源）
  游戏根/
    www/                 ← 内容根（游玩用）

Chaya（Next 本地项目）
  data/Chaya.app      ← 共用 NW.js 壳（不进 git；装一次）
  · 选游戏根、翻译、改文件、注入插件
  · 「开始游戏」→ 壳 + 当前 www（传参 / 重链 app.nw）
```

| 做什么                             | 在哪                                               |
| ---------------------------------- | -------------------------------------------------- |
| 翻译 / 改 data / 查变量名 / 管缓存 | Next 网页 + Node                                   |
| 游玩                               | 共用 `data/Chaya.app` + 当前内容根（不按作复制壳） |
| 局内改金钱/背包等                  | 游戏内插件（GameEdit 等）                          |

- 壳 **不进项目仓库**；缓存在工具 `data/Chaya.app`，品牌同名 `.app`
- 已打包进游戏的 `.app` 仍可直接当壳用（bundled）
- Web **不直接启动**未注册协议的裸路径；本地 Next 用 `open -n … --args`

---

## 3. 明确不做（MVP）

- Electron / 系统托盘
- 纯线上站读写本机游戏（可另做官网，不管本地盘）
- 壳放进 Application Support（纯浏览器写不了；本地 Next 也不再依赖该路径）

---

## 4. MVP 清单（摘要）

1. 初始化 Next.js + Tailwind + shadcn/ui
2. 绑定游戏根、解析 www
3. 插件注入、翻译启停与缓存 UI
4. 壳检测 / 安装到 `data/Chaya.app`（共用）
5. 「开始游戏」用壳 + 内容根启动

---

## 5. 一句话

**本地 Next（Node + Client）+ Tailwind/shadcn；游戏原位不复制；壳共用一份在 `data/Chaya.app`；管内容在 Web，游玩传参启动。**
