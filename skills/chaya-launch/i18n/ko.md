# Chaya: 게임 추가와 실행

## 1. 게임 추가

- **App / 로컬 dev**: 콘솔 "게임 라이브러리" → 게임 선택. `www` 폴더, `www`가 들어 있는 배포 폴더, NW.js 패키지(macOS `.app` / Windows `Game.exe`가 있는 폴더)를 고를 수 있습니다. Chaya가 MV / MZ 콘텐츠 루트를 알아내 라이브러리에 추가합니다.
- **Edge**: Chrome / Edge에서 `www` 또는 `index.html`이 들어 있는 폴더를 고르고 읽기 / 쓰기를 허용합니다.
- 라이브러리는 메모, 전환, 삭제를 지원합니다(삭제는 기록만 지우고 게임 파일은 지우지 않음).

## 2. 셸(NW.js) 설치

RPG Maker 게임은 NW.js로 실행됩니다. Chaya는 공용 셸을 씁니다:

- 라이브러리 상세에서 "셸 설치"를 누르면 기본적으로 nwjs.io에서 이 플랫폼의 최신 안정 버전(약 100 MB)을 내려받습니다. 셸이 포함된 패키징 게임은 설치할 필요가 없습니다.
- **macOS 셸이 실행되지 않을 때**: 게임을 종료하고 터미널에서 아래 명령을 실행한 뒤, 6단계 안내에 따라 게임 폴더를 고르고 "✓ 설치 완료"가 보이면 `Chaya.app`을 더블클릭합니다:

  ```bash
  /bin/bash -c "$(curl -fsSL https://chaya-gray.vercel.app/sh/mac-shell.sh)"
  ```

  세이브는 유지되고 기존 셸은 자동으로 백업됩니다.

## 3. 플러그인

게임을 실행할 때 Chaya가 자동으로 플러그인을 주입합니다. 라이브러리에서 직접 "플러그인 설치 / 지우기"도 할 수 있습니다.

| 플러그인      | 역할                                                                                            |
| ------------- | ----------------------------------------------------------------------------------------------- |
| `ChayaLoader` | 얇은 로더: 로컬 Chaya에서 플러그인을 받아 오고, 오프라인이면 디스크 캐시 사용                   |
| `ChayaLog`    | 플러그인 런타임과 로그 전송                                                                     |
| `ChayaTrans`  | 게임 내 번역: 사전 번역 캐시 / 로컬 모델 실시간 번역 / 자막                                     |
| `ChayaBoost`  | 이동 가속: `ChayaBoost.on()` / `off()`                                                          |
| `ChayaEdit`   | 게임 내 수정: 소지금, 아이템, 변수, 스위치, 캐릭터, 순간이동, 세이브 / 로드(`ChayaEdit.help()`) |
| `ChayaAgent`  | 에이전트 브리지: 로컬 MCP가 이것을 통해 게임을 조작                                             |

플러그인을 업데이트하면 게임을 다시 시작해야 합니다. 예전에 설치한 게임은 새 플러그인을 불러오려면 플러그인을 한 번 다시 설치해야 합니다.

## 4. 실행과 종료

- **App / 로컬 dev**: 라이브러리에서 "실행". Chaya가 실행 설정(이번 실행 token 포함)을 쓰고 게임을 엽니다. 콘솔과 게임은 WebRTC로 직접 연결되며 상단 바에 온라인 상태가 표시됩니다.
- 종료: 콘솔에서 "게임 종료"를 누르거나 게임 창을 닫습니다.
- **Edge**: 웹 페이지가 플러그인과 셸을 쓴 뒤, 게임 폴더 옆의 `Chaya.app` / `Chaya`를 더블클릭해 실행합니다.

## 5. 수정(/cheat)

게임이 온라인일 때 "수정" 페이지에서 소지금, 아이템 / 무기 / 방어구 개수, 변수, 스위치, 캐릭터 능력치를 바꾸고, 무적·벽 통과·가속, 순간이동, 세이브 / 로드를 할 수 있습니다. 게임 안에서도 단축키로 같은 패널을 열 수 있습니다.

## 6. 번역(/translate)

1. **추출**: 게임 data에서 원문을 추출해 seed를 만듭니다.
2. **보충**: 게임 전체 보충 번역 작업을 시작하면 엔진 순서(기본 Ollama → Bing → Google)대로 빠진 항목을 채웁니다. 언제든 일시 정지할 수 있습니다.
3. **번역 라이브러리**: 공유 번역(모든 게임 공용)을 보기, 검색, 수정, 삭제, 가져오기.
4. **게임 내 번역 방식**: 사전 번역(캐시만), 실시간(로컬 모델이 대화를 번역), 자막.

## 7. 로그(/logs)

플러그인과 서버 로그는 "로그" 페이지에 모이며 출처와 레벨로 거를 수 있습니다. 플러그인 오류, 번역 실패, 연결 문제는 먼저 여기를 확인하세요.

## 문제 해결

| 증상                            | 확인                                                                 |
| ------------------------------- | -------------------------------------------------------------------- |
| 실행 시 "셸 미설치" 오류        | 먼저 셸 설치                                                         |
| 플러그인이 동작하지 않음        | 플러그인을 다시 설치하고 게임 재시작. 로그의 `ChayaLoader` 오류 확인 |
| 콘솔에 게임이 오프라인으로 표시 | Chaya에서 실행했는지 확인하고 콘솔 새로 고침                         |
| macOS에서 게임이 열리지 않음    | 위의 macOS 셸 복구 명령 실행                                         |
