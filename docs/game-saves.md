# 辅助：游戏存档需求

> 状态：部分实现（快捷键网页同步、本机离线查看未做，见技术文档「分阶段」）
> 日期：2026-10-07
> 关联：[`input-assistance.md`](./input-assistance.md)（同属「辅助」）、[`edit-save-data.md`](./edit-save-data.md)（修改当前进度字段，非存档管理）
> 技术方案：[`technical/game-saves.md`](./technical/game-saves.md)

## 1. 背景

玩家经常忘记存档，或者遇到不能存档的游戏：有的游戏只允许在存档点保存，有的在长段剧情或迷宫里禁用存档，有的根本没有存档入口。一旦游戏崩溃、战斗失败或误操作，就会丢失大量进度。

「辅助」新增二级页面 **游戏存档**，提供两种互相独立的存档：

1. **自动存档**：按设定的间隔，在游戏处于可安全保存的时刻自动保存；也可以手动追加一份。数量有上限，超出后轮换删除最早的一份。
2. **快速存档**：固定 10 个槽（0–9），用快捷键或页面随时保存、读取，每个槽只保留一份，再次保存即覆盖。

两者分别展示在两个列表里，互不占用名额，互不影响。

Chaya 的存档与游戏原有存档**完全分开**：不占用、不覆盖游戏的存档槽，不出现在游戏自己的读档列表里；游戏原有存档也不会出现在 Chaya 的列表里。

### 1.1 术语

| 术语       | 含义                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 游戏存档   | 游戏自带存档功能产生的存档。本功能不读取、不修改。                                             |
| Chaya 存档 | 本功能产生的存档，即下面两类的统称。                                                           |
| 自动存档   | 轮换列表里的存档。按间隔自动生成，或在页面点击「立即存档」追加；超过最多个数时删除最早的一份。 |
| 快速存档   | 固定槽列表里的存档。共 10 个槽（槽 0–槽 9），每槽最多一份，再次保存即覆盖。                    |
| 读档前备份 | 旧版本读档时自动写入的当前进度；已取消，列表中留下的旧条目照常显示该标签。                     |
| 非安全时刻 | 附加标记，表示存档时游戏不处于可保存状态（例如战斗中强制保存），加载后进行中的状态会丢失。     |
| 可保存状态 | 游戏此刻适合保存的条件集合，见 §4.3。                                                          |

## 2. 产品目标

| 目标 | 玩家可感知的结果                                                           |
| ---- | -------------------------------------------------------------------------- |
| G1   | 开启自动存档后无需再操心，崩溃或失败后能回到最近几分钟内的进度。           |
| G2   | 不能存档的游戏也能随时保存和读档；常用的存档点放进快速存档槽，一键存取。   |
| G3   | 自动存档不会在战斗、剧情、对话等不安全的时刻保存，也不会打断游戏。         |
| G4   | 每次存档、读档在游戏画面里都有简短提示，玩家知道「正在存档」「存档成功」。 |
| G5   | 读档不额外写入存档，不挤占自动存档列表；读档失败时游戏保持原状。           |
| G6   | 自动存档的轮换永远不会删掉快速存档；游戏原有存档始终不受影响。             |

## 3. 入口与页面

- 入口：「辅助 › 游戏存档」，位于「键鼠工具」之后。Web 控制台（本机服务与 edge 部署）和游戏内浮层的「辅助」使用同一个页面，只换外壳，与键鼠工具一致。
- 页面标题下有一句说明：「定时自动存档，快速存档槽随时存取；与游戏自带存档互不影响」。
- 页面从上到下两张卡片，样式与「键鼠工具」的卡片一致。每张卡片从上到下：标题行（标题、ⓘ 悬停说明、简短说明，右侧为总开关）、设置区、列表工具栏、列表。列表工具栏左侧显示数量与占用空间，右侧是作用于列表的按钮。
  1. **自动存档卡片**
     - 标题行：标题「自动存档」与说明「按间隔自动保存，超过最多个数时删除最早的一份；设置所有游戏共用」，右侧为「开启自动存档」开关。开关切换成功后用通知提示「已开启 / 已关闭自动存档」，不在卡片里插入提示行（见 UI 风格指南 §6）。
     - 设置区：间隔、最多个数、游戏内迷你面板各占一行，与其他设置页一致：左侧标题，说明紧跟在标题下，右侧为输入框或开关。游戏内迷你面板见 §6.3。
     - 列表工具栏：左侧「N / 最多个数 份 · 占用 · 运行状态」，运行状态为「下次自动存档 03:12」「等待中：战斗中」「正在存档」「未开启」等，原位替换文字，见 §4；右侧两个按钮：
       - **立即存档**：立即追加一份新存档到本卡片的列表，见 §5.1；
       - **清空**：删除本卡片列表的全部存档。
     - 列表：轮换列表，见 §6.1。
  2. **快速存档卡片**
     - 标题行：标题「快速存档」与说明「10 个固定槽，用快捷键或下方按钮随时保存、读取」，右侧为「开启快速存档」开关，默认关闭，切换成功后同样用通知提示。开启后，用户在「辅助 › 快捷键」里设置的快速存档快捷键即可使用，页面上的「保存」也可用。关闭时不能存入槽位（快捷键不拦截、按键原样交给游戏，「保存」禁用）；已有存档仍可加载、删除。
     - 设置区：游戏内迷你面板开关一行（见 §6.3）；一行快捷键提示（如「⌘1 存到槽 1，⌥1 读取槽 1」）与「配置快捷键」按钮，跳到「辅助 › 快捷键」并自动滚动到「快速存档」分组，分组边框闪三次（Web 控制台切换页面，游戏内浮层切换分区）。
     - 列表工具栏：左侧「已用 N / 10 槽 · 占用」；右侧 **清空**：清空全部 10 个槽。
     - 列表：固定 10 个槽，见 §6.2。
- **设置所有游戏共用**，不依赖游戏：未选择、未连接时也能修改，连接游戏后自动生效。
- **列表跟随当前游戏**：只显示当前所选或已连接游戏的存档，切换游戏后随之切换。
- 打开页面时先读取通用设置，读回前两张卡片整体显示骨架屏（形状与卡片一致），避免先显示默认值再跳变；读取失败时按默认值显示并提示错误。
- 设置读回后两张卡片**始终显示**：未选择、未连接或读取中时，设置区照常可改；只有列表区域换成对应的空态或骨架屏，列表工具栏（数量、立即存档、清空）随列表一起隐藏，详见 §3.1、§10。

### 3.1 页面状态

两张卡片的状态一致：

| 状态              | 设置区             | 列表工具栏               | 列表                                       |
| ----------------- | ------------------ | ------------------------ | ------------------------------------------ |
| 读取通用设置中    | 骨架屏             | 骨架屏                   | 骨架屏                                     |
| 读取存档列表中    | 可修改             | 不显示                   | 骨架屏                                     |
| 未选择游戏        | 可修改             | 不显示                   | 空态「请先选择游戏」                       |
| 未连接            | 可修改，连接后生效 | 不显示                   | 空态「请先连接游戏」                       |
| 已连接            | 全部可用           | 全部可用，摘要含运行状态 | 全部可用                                   |
| 存档 / 读档进行中 | 同已连接           | 按钮显示进行中并禁用     | 「加载」「保存」禁用，进行中的行显示加载态 |
| 读取失败          | 可修改             | 不显示                   | 显示错误与「重试」                         |

- 卡片说明后显示合计：自动存档「12 / 30 份 · 18 MB」，快速存档「已用 4 / 10 槽 · 6 MB」。两类合计超过 1 GB 时在页面顶部提示，建议清理。

## 4. 自动存档

### 4.1 设置项（自动存档卡片的设置区）

| 设置         | 默认值     | 范围 / 说明                                                                                   |
| ------------ | ---------- | --------------------------------------------------------------------------------------------- |
| 开启自动存档 | 关         | 所有游戏共用，见 §10。                                                                        |
| 间隔         | 5 分钟     | 1–60 分钟。                                                                                   |
| 最多个数     | 30         | 15–120。自动存档列表超过此数量时，自动删除最早的一份，见 §6.1。                               |
| 存储位置     | 存到游戏中 | 「存到游戏中」或「存到 Chaya 本机」，见 §10。快速存档卡片设置区有同样一行，两个列表分别设置。 |

- 以下行为固定，不提供设置：游戏自身禁用存档（如剧情段落）时照常保存；每次存档、读档都在游戏画面提示，见 §7。
- 「开启自动存档」只控制定时保存。关闭后，自动存档列表仍可查看、加载，也可以用列表上方的「立即存档」手动追加。
- 调小「最多个数」时，若当前数量超过新上限，保存设置前确认「将删除最早的 N 份自动存档」，确认后立即删除。

### 4.2 计时

- 按**游戏实际运行时间**计时：游戏停在标题画面、窗口失焦或暂停、Chaya 面板打开导致游戏暂停时不计时。
- 距上一次进入自动存档列表的保存（定时或「立即存档」按钮）满一个间隔即视为「到期」。快速存档不影响计时。
- 如果自上次自动存档以来玩家没有任何操作（键盘、鼠标、触摸），角色也没有移动或换地图（例如挂机），到期也不重复保存，直到玩家再次操作。
- 读档成功后重新开始计时，避免刚读档就被一次自动存档挤掉旧存档。
- 修改间隔后从修改时刻重新计时；关闭再开启自动存档也重新计时。

### 4.3 可保存状态

到期后，只有下列条件**同时满足并持续 1 秒**才保存：

| 条件                       | 拦住的情况                   |
| -------------------------- | ---------------------------- |
| 处于地图画面且未在切换场景 | 标题、菜单、商店、战斗等画面 |
| 不在战斗中                 | 回合制战斗                   |
| 没有事件正在执行           | 剧情、过场、事件演出         |
| 没有对话框或选项           | 对话、选项、数字输入         |
| 不在传送途中               | 切换地图                     |
| 角色没有在移动             | 走到一半                     |

- 条件不满足时持续等待，没有超时；一旦满足立即保存。
- 自动存档列表工具栏的摘要里显示倒计时，例如「下次自动存档 03:12」；或者显示等待原因，例如「等待中：战斗中」「等待中：剧情进行中」；游戏窗口未激活或局内面板打开时不计时，显示「计时暂停 · 剩 03:12」。等待状态不在游戏画面里提示，避免打扰。
- 已知识别不了的情况，写在自动存档卡片标题旁信息图标的悬停说明里（页面上不常驻显示），与保存条件、轮换删除的说明放在一起：
  - 在地图上直接进行的即时战斗（动作战斗类插件）；
  - 用并行事件制作的过场。

  这类游戏建议改用快速存档。

## 5. 保存与读档

### 5.1 自动存档卡片的「立即存档」

- 点击自动存档列表上方的「立即存档」，立即追加一份存档到该卡片列表的最上方，标签「手动」。名称自动取地图名，不需要填写。
- 这份存档与定时生成的存档一样参与轮换：列表超过最多个数时，最早的一份会被删除，不论它是定时生成还是手动追加。需要长期保留的存档应放进快速存档槽。
- 当前处于不可保存状态时，不直接保存，而是提示原因，例如「战斗中无法存档」，并提供「仍然保存」：
  - 这类存档附加「非安全时刻」标记；
  - 战斗、事件执行进度不会被保存，加载后回到当时所在的地图，战斗和正在进行的剧情不会恢复。
- 在游戏内浮层里保存时，游戏因面板打开而暂停，但仍处于地图画面，按可保存状态判断；缩略图只截游戏画面，不包含面板。

### 5.2 快速存档

每个游戏固定 10 个快速存档槽，编号 0–9。

**保存到槽**

- 两种方式：
  - 游戏中按快捷键「快速保存到槽 N」；
  - 在快速存档卡片中点击某个槽的「保存」。
- 槽为空时直接保存。槽已有存档时：
  - 快捷键直接覆盖，不弹确认框；
  - 页面操作弹出确认「覆盖槽 N 的存档？」。
- 只在可保存状态下执行，条件同 §4.3；游戏自身禁用存档时同样允许。
  - 快捷键遇到不可保存状态时不写入，游戏内提示原因，例如「战斗中无法存档」。
  - 页面操作遇到不可保存状态时提示原因，并提供「仍然保存」，存档附加「非安全时刻」标记。
- 快速存档不参与自动存档的轮换，永远不会被自动删除。

**读取槽**

- 两种方式：
  - 游戏中按快捷键「快速读取槽 N」：直接读取，不弹确认框；
  - 在快速存档卡片中点击该槽的「加载」：先确认，见 §5.3。
- 槽为空时提示「槽 N 为空」，不做任何改动。

**快捷键**

- 在「辅助 › 快捷键」新增分组「快速存档」，共 20 项：
  - 「快速保存到槽 0」…「快速保存到槽 9」，默认 `Ctrl+0`…`Ctrl+9`（macOS 显示为 `⌘0`…`⌘9`）；
  - 「快速读取槽 0」…「快速读取槽 9」，默认 `Alt+0`…`Alt+9`（macOS 显示为 `⌥0`…`⌥9`）。
  - 数字键按物理键位识别：macOS 上 `⌥` 加数字会输入特殊字符（如 `⌥3` 输入 `£`），也必须能触发；小键盘数字与主键盘数字视为同一按键。
- 前提是在快速存档卡片打开「开启快速存档」（默认关闭）；开启后，设置了的快捷键即可使用。关闭时这些按键不拦截，交给游戏处理。
- 与其他快捷键一样，可以改绑，支持全局与本游戏两种范围；不需要某个默认绑定时，关闭该项的开关即可。默认绑定与已有快捷键冲突时，以已有的为准；面板关闭时也生效，焦点在输入框里时不触发。按住不放只算一次，不会连续保存或读取。
- 快捷键在游戏中执行。在 Web 控制台修改的绑定必须同步到游戏才生效；目前快捷键配置在网页和游戏之间各存一份、互不同步，本功能上线前需要先补上同步（与键鼠规则的同步方式一致）。

### 5.3 读档（两个列表通用）

- 点击存档行右侧的「加载」按钮加载该存档。加载前需要确认，确认框写明来源（自动存档或槽 N）、存档名称和时间，以及「当前未保存的进度将被替换」。快速读取快捷键不弹确认框。
- 在地图、菜单、战斗中，甚至标题画面，都可以加载。加载完成后回到存档所在的地图和位置。
- 读档本身不写入任何存档。读档完成后自动存档从头计时：满一个间隔、且这段时间内有操作或进度变化，才会存下一份；读档后一直不动不会重复存同一进度。
- 存档与当前游戏的标识或版本不一致时（例如游戏更新过），加载前额外提示「此存档来自其他版本，可能无法正常加载」；快捷键读取时在游戏内提示后不执行，需要到页面确认后加载。
- 读档成功后：
  - 游戏内浮层自动关闭，直接回到游戏画面；Web 控制台停留在当前页面。
  - 正在运行的键鼠连发、键鼠动作全部停止并释放按键，避免带入新进度。
  - 「修改」里的锁定和运行设置（如移速、遇敌开关）按当前配置重新应用，与读取游戏存档后的行为一致。
  - 实时翻译、迷你地图等其他功能照常继续。
- 读档失败（存档损坏、与游戏不兼容等）时游戏保持读档前的状态，不回到标题画面；页面显示失败原因。

## 6. 两个列表与迷你面板

### 6.1 自动存档卡片的列表（轮换）

- 只列出当前游戏的自动存档，按保存时间倒序，一行一份。
- 每行左侧是存档信息：
  - 缩略图：游戏画面等比缩小，宽约 160 px；读不到画面时显示占位图标；
  - 名称：地图显示名，没有显示名时用地图编号，例如「地图 12」；
  - 标签：「自动」「手动」二选一（旧版本留下的条目可能显示「读档前备份」）；「非安全时刻」作为附加标签并列；
  - 游戏时长：`时:分:秒`，例如 `12:03:45`；
  - 保存时间：相对时间，例如「3 分钟前」，悬停显示完整日期时间。
- 每行右侧：
  - **加载**：主操作按钮，见 §5.3；
  - **删除**：图标按钮，删除前确认。
- **轮换规则**：每次有新存档进入本列表后，若数量超过「最多个数」，删除保存时间最早的一份，直到不超过上限。删除不提示。
- 列表上方的「清空」删除本列表全部存档。确认框写明份数，并说明「快速存档和游戏自带存档不受影响」。不改变自动存档设置。
- 列表为空时居中显示空态「还没有自动存档」，「清空」禁用。
- 自动存档列表和快速存档槽位都限制最大高度（约 6 行），超出后在卡片内滚动，使用自定义滚动条；迷你面板内列表同样用自定义滚动条。

### 6.2 快速存档卡片的列表（固定槽）

- 始终显示 10 行，按槽号 0–9 排列，不随保存时间重排。
- 已有存档的槽：
  - 左侧：槽号、缩略图、名称、游戏时长、保存时间，规则同 §6.1；有「非安全时刻」时显示附加标签；
  - 右侧：**加载**（主操作）、**保存**（覆盖，需确认）、**删除**（清空该槽，需确认）。
- 空槽：
  - 左侧：槽号与「空」；
  - 右侧：**保存**；「加载」和「删除」不显示。
- 槽位行不显示快捷键；设置区说明里给出示例（如「⌘1 存到槽 1，⌥1 读取槽 1」）。
- 列表上方的「清空」清空全部 10 个槽。确认框写明有存档的槽数，并说明「自动存档和游戏自带存档不受影响」。全部为空时「清空」禁用。

两个列表的缩略图都在游戏内提示出现之前截取，不包含 Chaya 的提示和面板。

### 6.3 游戏内迷你面板

两个列表各有一个游戏内迷你面板，方便不打开浮层就能存读档。做法与「迷你地图」「旅伴」一致，使用同一种浮动小面板。

- **外观与操作**：标题栏可拖动；四边可调整大小；标题栏右侧有「钉住」「最小化」「关闭」按钮。钉住后不能拖动、不能调整大小，再点一次取消。透明度固定（略透），暂不提供调整。位置、大小、是否钉住按面板分别记住。
- **默认位置**：迷你地图在右上，旅伴 在右下。自动存档面板在左上，快速存档面板在左下，首次打开时互不遮挡。窗口太矮放不下同一侧的两个面板时，两者各占一半高度。
- **开关**：
  - 两张卡片的设置区各有一行「游戏内迷你面板」开关，默认关闭。
  - 与迷你地图、旅伴 的开关存在同一处（工具设置），所有游戏共用。和它们一样只在 Chaya App 或本机服务中可用；不可用时开关禁用，并说明原因。
  - 开关切换成功后用通知提示「已开启 / 已关闭自动存档面板」。
- **关闭按钮**：只在本次游戏中隐藏面板，开关保持开启，下次进入游戏仍显示。要彻底关闭，用开关或快捷键（§6.4）。
- **显示范围**：只在游戏画面上显示，Web 控制台不显示。游戏内浮层打开时照常显示，与迷你地图一致。
- **自动存档面板**：
  - 顶部一行：左侧「N / 最多个数 份 · 运行状态」，规则同卡片的列表工具栏；右侧「立即存档」图标按钮。
  - 下方按保存时间倒序列出自动存档，一行一份：名称、标签、相对保存时间，右侧「加载」图标按钮。
  - 不显示缩略图，不提供删除和清空（在页面里操作）。
  - 没有存档时在面板正文水平、垂直居中显示「还没有自动存档」。
- **快速存档面板**：
  - 固定 10 行，按 `#0`–`#9` 排列：槽号、名称与相对保存时间（空槽显示「空」），右侧「保存」「读取」两个图标按钮。
  - 未开启快速存档时，顶部一行说明「快速存档未开启」，「保存」禁用，「读取」照常可用。
  - 空槽的「读取」禁用。
- **面板按钮**：都是无边框图标按钮，悬停显示文字提示（如「保存到槽 3」「读取槽 3」「立即存档」「加载」），面板保持紧凑。
- **操作规则与页面一致**：覆盖槽位、加载前确认；不可保存状态下提示原因并提供「仍然保存」；同一时间只执行一项操作，进行中的按钮显示加载态。结果由游戏内提示显示（§7），面板不另插入提示行。
- 存档运行时未就绪（例如插件版本过旧）时，面板内容区显示原因。

### 6.4 迷你面板快捷键

- 「辅助 › 快捷键」新增「迷你面板」分组，放在「面板」分组之后，共 4 项：
  - 开关迷你地图；
  - 开关旅伴；
  - 开关自动存档面板；
  - 开关快速存档面板。
  - 之后新增「开关迷你面板管理」，见 [`mini-panels.md`](./mini-panels.md) §4.4，分组共 5 项。
- 默认不绑定，玩家自行设置；可以改绑、清除、暂停，可以按游戏覆盖，规则与其他快捷键相同。
- 按下时：
  - 对应面板正在显示：关闭它的开关。
  - 面板未显示（开关关闭，或本次被关闭按钮隐藏）：打开开关并显示面板。
  - 与页面上的开关是同一份设置，页面开关同步变化。
- 迷你地图只在地图场景显示，旅伴 在 Chaya 助手侧栏打开时隐藏。不在这些场景时按快捷键只切换开关，回到对应场景后按开关状态显示。
- 输入框聚焦时不触发；面板关闭或打开时都可用。
- 工具设置不可用（不在 Chaya App 或本机服务中）时，按键不拦截，原样交给游戏。

## 7. 游戏内提示

存档和读档在游戏画面里给出简短提示，视觉和行为与实时翻译的状态提示一致：右下角先出现小圆形图标，再展开成文字，结束后数秒内自动收起。

| 时机     | 提示                                     | 样式                  |
| -------- | ---------------------------------------- | --------------------- |
| 开始存档 | 「存档中」                               | 蓝色转圈图标          |
| 存档成功 | 「已存档」/「已自动存档」/「已存到槽 3」 | 绿色 ✓，约 2 秒后收起 |
| 存档失败 | 「存档失败」/「战斗中无法存档」等原因    | 红色 ×，约 4 秒后收起 |
| 开始读档 | 「读档中」                               | 蓝色转圈图标          |
| 读档成功 | 「已读档」/「已读取槽 3」                | 绿色 ✓，约 2 秒后收起 |
| 读档失败 | 「读档失败」/「槽 3 为空」               | 红色 ×，约 4 秒后收起 |

- 提示不拦截鼠标，也不抢键盘焦点，不影响操作游戏。
- 与实时翻译提示共用同一个角落。两者同时出现时上下排列，不互相遮挡；翻译提示避让对话框时，存档提示一起避让。
- 失败的具体原因（例如磁盘空间不足、存档数据损坏）在页面上显示，游戏画面只显示简短状态。
- 所有存档、读档（包括定时自动存档）以及失败都会提示，不提供关闭选项，见 §4.1。
- 系统开启「减少动态效果」时，转圈和展开动画减弱，与翻译提示一致。

## 8. 并发与时序

- 同一游戏同时只执行一项存档或读档操作。
  - 正在保存时，再按同一个快速保存键忽略；其他保存请求（页面保存、其他槽）排队，按顺序执行。
  - 正在保存时发起读档，等保存完成后再读档。
  - 正在读档时，所有保存请求（包括定时自动存档）都不执行；快捷键操作提示「正在读档」。
- 定时自动存档到期时若有其他操作在进行，等其完成后再判断；页面「立即存档」成功后定时器重新计时，不会紧接着再存一次。
- 操作进行中 Web 端断开连接或切换游戏时，游戏侧继续把这项操作做完；重新连接后列表显示实际结果。
- 游戏在存档写入过程中被关闭或崩溃时，已有存档不受影响，只是这一份没有保存成功；快速存档覆盖失败时保留该槽的旧存档。

## 9. 与游戏存档的区分

- Chaya 存档单独存放，不写入游戏的存档目录或存储，不改变游戏的存档槽。快速存档的「槽 0–9」是 Chaya 自己的槽位，与游戏存档编号无关。
- 存档内容与游戏自身存档包含的进度相同，包括其他插件挂进存档的数据。
- 游戏自带的存档、读档功能照常使用，Chaya 不拦截也不修改。
- 后续可选能力（本期不做）：把某份 Chaya 存档「复制到游戏存档槽」，方便之后不用 Chaya 也能接着玩。

## 10. 多端与存储

- 存档按游戏存放，不跨游戏共享；自动存档与快速存档分开存放。存放位置在两张卡片的「存储位置」里分别设置：
  - **存到游戏中**（默认）：存在该游戏目录里，跟随游戏。游戏所在环境没有文件系统时（例如在浏览器里运行），存在该环境的浏览器存储里，同样与游戏自身存档分开。
  - **存到 Chaya 本机**：存在 Chaya 本机服务的数据目录，不写入游戏目录。只在 Chaya App 或本机服务中可用，否则该选项禁用并说明原因。游戏运行时 Chaya 本机服务未运行，该列表显示「无法连接 Chaya 本机服务」与「重试」，无法在该列表保存或读档，另一列表不受影响。
  - 切换位置不搬动已有存档：原位置的存档保留，切回即可看到。切换成功后通知「自动存档已改为「存到 Chaya 本机」」等。
- 自动存档与快速存档的设置是一份通用设置，所有游戏共用：本机模式存在本机服务的数据目录，edge 模式与游戏内浮层存在当前环境的浏览器存储。每个游戏目录另存一份副本，网页关闭后游戏仍按它运行。连接游戏时比较两份，以较新的为准：网页较新则下发给游戏，游戏较新（例如在游戏内浮层改过）则写回通用设置。
- 未连接时调小「最多个数」不会提示删除；连接后游戏按新上限立即删除多出的最早存档。
- 保存、加载、删除等操作都由游戏侧执行，Web 控制台需要已连接游戏才能操作。
  - 未连接时两张卡片照常显示，设置可改，列表区域显示「请先连接游戏」。
  - 本机模式未连接时只读查看存档列表属于后续阶段，见技术文档「分阶段」。
- 写入存档采用「先写临时文件、成功后替换」的方式；写入失败不会损坏已有存档。
- 存档只保存在本机，不上传到任何服务器。
- 「清除 Loader」、卸载或更新插件不会删除 Chaya 存档；删除存档只能通过列表中的删除或「清空」。

## 11. 日志与多语言

- 每次存档、读档、删除、清空、轮换删除都写入「日志」页，记录：
  - 操作类型、所属列表（自动存档 / 槽 N）、触发来源（定时、页面、快捷键）；
  - 耗时、结果、失败原因。
- 自动存档的等待不写日志，只在状态变化时（开始等待、等待结束）各记一条，避免刷屏。
- 页面文案、迷你面板、确认框、游戏内提示和报错支持中、英、日、韩四种语言，跟随 Chaya 的界面语言。日志只写中文，与其他模块一致。

## 12. 边界与风险

- 少数插件把数据存放在游戏存档之外（单独的文件、全局状态），或者在游戏存档时做额外处理。这些数据不包含在 Chaya 存档里，读档后可能不完整。页面说明里需要提示这一点。
- 大型游戏生成一次存档可能有轻微卡顿。定时自动存档只在空闲时刻执行，间隔下限为 1 分钟。
- 战斗、正在执行的事件、对话等进行中的状态不会被保存。
- 自动存档列表里的「手动」和「读档前备份」也会被轮换删除；页面说明里提示「需要长期保留请存到快速存档槽」。
- 本期不做：
  - 云同步与跨设备；
  - 存档文件导入导出；
  - 编辑存档内容（由「修改 › 数据」负责）；
  - 进入新地图时自动存档；
  - 复制到游戏存档槽；
  - 存档重命名、锁定、筛选，快速存档槽数量调整；
  - 在两个列表之间移动或复制存档；
  - 退出游戏时自动存档；
  - Chaya 助手（Agent）调用存档、读档，后续接入时按高风险操作处理，需要玩家授权。

## 13. 验收标准

**自动存档**

1. 开启自动存档、间隔设为 1 分钟，在地图上自由行动，约 1 分钟后出现「存档中 → 已自动存档」，自动存档列表新增一份「自动」存档。
2. 到期时正处于战斗、对话或事件中，不保存，自动存档卡片显示对应的等待原因；结束后回到地图约 1 秒内完成保存。
3. 游戏停在标题画面、窗口失焦或挂机不动时，不产生新的自动存档。
4. 「最多个数」只能设为 15–120；默认 30。自动存档列表达到上限后再新增一份，最早的一份被删除，数量保持为上限值。
5. 把「最多个数」从 30 调到 15 时提示将删除的份数，确认后列表只剩最新的 15 份。
6. 点击自动存档列表上方的「立即存档」，列表最上方新增一份「手动」存档；它同样参与轮换。
7. 战斗中点击「立即存档」，先提示原因；选择「仍然保存」后生成带「非安全时刻」标签的存档，加载后回到战斗前所在的地图。
8. 自动存档卡片「清空」后列表为空，快速存档卡片不变。

**快速存档**

9. 快速存档卡片始终显示槽 0–9 共 10 行，行首标为 `#0`–`#9`（迷你面板相同）；空槽只显示「保存」。未连接游戏时两张卡片仍显示且设置可改，只有列表区域显示「请先连接游戏」；连接后游戏按修改后的设置运行。
10. 「辅助 › 快捷键」出现「快速存档」分组，共 20 项，默认绑定 `Ctrl+0–9` 保存、`Alt+0–9` 读取，可以改绑和清除。快速存档卡片的「开启快速存档」默认关闭，此时按 `Ctrl+3` 交给游戏、不存档，「保存」禁用；打开后快捷键可用。槽位行不显示快捷键，按键示例只在设置区说明里出现。点击「配置快捷键」后，快捷键页自动滚动到「快速存档」分组。
11. 打开快速存档快捷键后，面板关闭时在地图上按 `Ctrl+3`，提示「已存到槽 3」，槽 3 显示新存档；再次按下覆盖槽 3，列表仍是 10 行。
12. 页面上对已有存档的槽点击「保存」，先确认覆盖，确认后更新该槽。
13. 按 `Alt+3` 直接读取槽 3，提示「已读取槽 3」；槽为空时提示「槽 3 为空」，游戏不受影响。
14. 战斗中按 `Ctrl+3`，不写入并提示「战斗中无法存档」，槽 3 原有存档保留。
15. 按住 `Ctrl+3` 不放只保存一次；保存进行中连按不会重复写入。
16. 自动存档轮换无论删除多少份，快速存档都不受影响；快速存档卡片「清空」后自动存档卡片不变。

**读档与通用**

17. 点击任一列表的「加载」并确认后，游戏进入该存档，列表不新增条目；开启自动存档时，下一份要等满一个间隔且期间有操作。
18. 在游戏禁用存档的段落里，页面保存和快速存档都能正常保存，读档后进度一致：地图、位置、队伍、物品、开关、变量都恢复。
19. 在标题画面加载 Chaya 存档，能直接进入游戏。
20. 读档成功后，游戏内浮层自动关闭，正在运行的键鼠连发停止，「修改」里的锁定继续生效。
21. 存档文件损坏时读档失败，游戏保持原状态，页面显示失败原因。
22. 切换游戏后，两个列表只显示新游戏的存档。
23. 游戏自带的存档槽和读档列表在使用前后完全不变。
24. 存档、读档在游戏画面都有提示，并与实时翻译提示同时显示且不重叠；定时自动存档同样提示。
25. Web 控制台与游戏内浮层显示同一份设置和两个列表；在一端操作后，另一端刷新即可看到。
26. 在 Web 控制台修改快速存档快捷键后，游戏中按新的按键生效。
27. 每次存档、读档、轮换删除在「日志」页有对应记录。
28. 切换到英文、日文、韩文界面后，页面和游戏内提示显示对应语言。

**迷你面板**

29. 打开自动存档卡片的「游戏内迷你面板」开关，游戏画面左上出现「自动存档」小面板；顶部显示数量和倒计时，点「立即存档」后列表最上方新增一份，点「加载」并确认后读档。
30. 打开快速存档卡片的「游戏内迷你面板」开关，游戏画面左下出现「快速存档」小面板，固定 10 行；未开启快速存档时「保存」禁用；开启后点「保存」写入该槽，已有存档时先确认覆盖。
31. 四个迷你面板（迷你地图、旅伴、自动存档、快速存档）可以拖动、调整大小、固定、最小化，下次进入游戏位置不变；首次打开时互不遮挡。
32. 点面板的关闭按钮后本次游戏不再显示，页面开关仍为开启；重新进入游戏后面板再次出现。
33. 「辅助 › 快捷键」出现「迷你面板」分组，共 4 项（加上迷你面板管理后为 5 项，见 `mini-panels.md`），默认未绑定。绑定后按下，对应面板显示时关闭、未显示时打开，页面开关同步变化；输入框聚焦时按下不触发。

## 14. 待确认

- 快速存档默认键位 `Ctrl+0–9` / `Alt+0–9` 是否与常见游戏冲突，是否改为其他组合。默认绑定只在玩家从未设置过该项时生效；与已有快捷键冲突时以已有的为准，该项默认绑定不生效。
