# 增强寻路需求

> 状态：已实现。实现见 [技术文档](technical/smart-path.md)。

## 1. 背景

RPG Maker MV / MZ 自带的点击移动只在角色附近约 12 步内找路，找不到完整路线时朝「直线离目标最近」的方向走。它也不管路上会不会踩到事件。常见问题：

- 点击上方较远的位置，角色直接往上走，撞墙后停下，不会绕路。
- 点击屋子后面，角色走向门口，踩到传送事件进了屋。
- 点击屋顶、墙内等走不到的格子，角色同样往门口凑。

游戏中的 AI（旅伴、Agent 的「走到某格」）用的是同一套寻路，问题相同。

## 2. 名词

| 名词       | 含义                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| 点击移动   | 运行页已有开关：点击地图让角色走过去。                                             |
| 能力增强   | 「辅助」中新增的页面，放改进游戏原有操作的开关；增强寻路是其中第一项。             |
| 增强寻路   | 本需求新增的开关：点击移动时先算出完整路线再走。                                   |
| 会触发的格 | 踩上去就会启动的事件所在格：接触触发（玩家接触、事件接触）的传送门、机关、NPC 等。 |

## 3. 设置

- 「辅助」新增页面「能力增强」（Web `/assist/enhance` 与局内浮层「辅助」同一页面），页头说明「让游戏里的操作更顺手，例如点击移动时绕路而不是直线乱撞」。
- 页面内一张卡片：「增强寻路」开关，描述说明绕开障碍、不经过门和传送点、点中门时照常进入、游戏 AI 同样生效。
- 默认开启。与迷你地图、旅伴等设置一样是全局设置，所有游戏共用；在 Web 或游戏内改动后，游戏几秒内同步生效。
- 与运行页「点击移动」相互独立：点击移动关闭时玩家点击不会移动，但游戏中的 AI 走到某格仍按本开关（见 §5）。

## 4. 行为

开启时：

1. **完整路线**：点击地图某格后，在整张地图范围内找最短路线并沿路线逐格移动，不受距离限制。
2. **绕开会触发的格**：路线不经过会触发的格。点击的正是那一格时照常走过去并触发（例如点门进屋、点机关）。
3. **走不到时**：目标走不到（屋顶、墙内、被会触发的格隔开）时，走到能到达且离目标最近的格子停下；离目标只差一格，或隔着柜台时转向目标（点击 NPC、隔柜台点店员时照常对话）。再次点击同一格会重新计算。
4. **遇到阻挡**：走动的 NPC 挡住下一步时重新规划；行走途中点击新位置，走完当前这一格后立即按新目标规划。
5. **按住拖动**：与 RPG Maker 原有的鼠标操作一致，按住鼠标约 15 帧（1/4 秒）后，目的地每帧跟随指针所在格，角色沿完整路线朝指针走；松开后走到最后指向的格子。
6. **与原规则一致**：能否通行完全按游戏自身规则（含单向通行、柜台、其他插件对通行的修改），不会走出原本走不了的路。
7. **不接管的情况**：开启「穿墙」、乘坐载具时沿用游戏原有寻路。
8. **不卡顿**：一次规划最多查看约 3 万格（约 180×180），最大地图（256×256）上也在一帧左右完成；超出时按走不到处理，先走到已找到的最近格。
9. 键盘、手柄移动不受影响。
10. 插件加载后即生效，不依赖是否连接 Chaya、是否保存过修改设置。

关闭时完全沿用游戏原有寻路。

## 5. 游戏中的 AI

旅伴与 Agent 的「走到某格」（`player.moveTo`，含逐格模式）使用同一套寻路，开关开启时同样绕路、不误进门。

## 6. 不做

- 不加寻路参数（搜索范围、是否绕事件等）配置。
- 不做八方向移动；沿用游戏的四方向。
- 不避开伤害地形、遇敌区域。

## 7. 验收

1. 「辅助 › 能力增强」页面出现「增强寻路」开关，默认开启；Web 与局内浮层是同一页面。
2. 开关状态保存在工具设置中，重启游戏后保持。
3. 开启时，点击需要绕行的远处位置，角色沿可行路线走到目标，中途不撞墙停住。
4. 开启时，点击屋子后面，角色绕到屋后，不进门；点门则进屋。
5. 开启时，点击屋顶或墙内，角色停在离该处最近的可达格，不进门。
6. 开启时，点击 NPC，角色走到 NPC 旁并对话。
7. 路上有 NPC 走动挡路时，角色重新规划后继续前往。
8. 循环地图上跨边界的目标走最短方向。
9. 关闭时行为与原版一致；开启「穿墙」或乘坐载具时行为与原版一致。
10. 旅伴 / Agent 让角色走到某格时，开启增强寻路后同样绕路、不误进门。
11. 行走途中点击另一处，角色立即改道前往新位置（开启、关闭增强寻路都如此）。
12. 按住鼠标拖动，角色跟随指针走；拖到屋子后面时绕路，不进门；松开后再移动指针不影响目的地。
13. 新游戏首次启动（未保存过任何修改设置）时增强寻路同样生效。
