# Chaya: 소개와 설치

Chaya는 RPG Maker MV / MZ 게임용 로컬 도구 모음입니다. 게임 라이브러리 관리, NW.js 셸 설치, 게임 내 플러그인(수정, 가속, 번역) 주입, 일괄 보충 번역, 로그 보기를 제공하고, 에이전트가 게임을 직접 조작할 수 있는 로컬 MCP도 제공합니다.

## 세 가지 형태

| 형태         | 무엇인가                                | 할 수 있는 것                                                        | 할 수 없는 것                                            | 추천 대상              |
| ------------ | --------------------------------------- | -------------------------------------------------------------------- | -------------------------------------------------------- | ---------------------- |
| **Edge**     | 웹 버전 `https://chaya-gray.vercel.app` | 브라우저에서 게임 폴더를 허용한 뒤 플러그인과 셸 쓰기, App 다운로드  | 게임 프로세스 실행, 공유 번역 라이브러리, 로컬 모델, MCP | 설치 없이 먼저 써 보기 |
| **로컬 dev** | Node로 소스를 직접 실행(`pnpm dev`)     | 전부: 라이브러리, 원클릭 실행, 보충 번역, 번역 라이브러리, 로그, MCP | —                                                        | 개발자, 코드를 고칠 때 |
| **App**      | 데스크톱 앱(macOS / Windows)            | 로컬 dev와 같음. 더블클릭으로 실행, 데이터는 시스템 앱 폴더에 저장   | —                                                        | 일상 사용(추천)        |

선택 기준: 평소 플레이와 번역은 **App**, 에이전트가 게임을 조작하게 하려면 **App 또는 로컬 dev**, 잠깐 플러그인만 설치하려면 **Edge**.

## App 설치(추천)

1. Chaya 홈페이지의 다운로드 영역에서 Apple 실리콘(M 시리즈), Intel Mac, Windows x64 중 하나를 고릅니다. 추천 항목은 자동으로 표시됩니다.
2. **macOS는 한 줄 명령 설치를 추천**("손상되었기 때문에 열 수 없습니다"가 나오지 않음). 터미널에 붙여 넣고 Return:

   ```bash
   /bin/bash -c "$(curl -fsSL https://chaya-gray.vercel.app/sh/install.sh)"
   ```

3. macOS 수동 설치: zip을 풀고 `Chaya.app`을 "응용 프로그램"으로 끌어 놓습니다. "손상됨"이 뜨면 `xattr -cr /Applications/Chaya.app`을 실행한 뒤 다시 열거나, App을 우클릭 → "열기" → "열기".
4. Windows: zip을 풀고 `Chaya.exe`를 실행합니다.
5. App을 실행하면 콘솔 창이 열리며 주소는 `http://127.0.0.1:3927`로 고정입니다.

## 로컬 dev 설치

준비물: Node ≥ 22.19, pnpm 9.

```bash
git clone https://github.com/DavidKk/chaya.git
cd chaya
pnpm i
pnpm dev          # 로컬 모드, 127.0.0.1:3927에서 대기
```

- 터미널에 **인증 링크**(`http://127.0.0.1:3927/api/access?token=…`)가 출력되니 그것으로 콘솔을 엽니다. token은 `data/access/token`에도 저장됩니다.
- 다른 실행 방법: `pnpm dev:lan`(LAN에서 접속 가능), `pnpm dev:app`(Electron 창 포함, App과 동일), `pnpm dev:edge`(로컬에서 Edge 재현, 테스트용).
- 게임 내 플러그인을 고치면 `pnpm dev`가 자동으로 다시 빌드하고 게임은 핫 리로드됩니다.

## Edge 사용

1. **Chrome 또는 Edge**에서 `https://chaya-gray.vercel.app`을 엽니다(Safari / Firefox는 폴더 허용을 지원하지 않음).
2. 라이브러리에서 로컬 게임 폴더(`www` 또는 `index.html` 포함)를 고르고 읽기 / 쓰기를 허용합니다.
3. 웹 페이지가 플러그인과 셸을 게임 폴더에 씁니다. 그 뒤 로컬에서 더블클릭해 게임을 실행합니다(웹 페이지는 프로세스를 실행할 수 없음).
4. 공유 번역 라이브러리, 게임 전체 보충 번역, MCP 등 로컬 디스크가 필요한 기능은 Edge에서 쓸 수 없으니 App 또는 로컬 dev를 쓰세요.

## 인증과 보안

- 콘솔과 API에는 관리 token이 필요합니다. 인증 링크는 자기 컴퓨터에서만 열고 공유하지 마세요.
- 게임 플러그인은 실행할 때마다 생성되는 실행 token을 쓰며, 자기 게임 세션에만 접근할 수 있습니다.

## 자주 묻는 질문

| 문제                          | 해결                                                                               |
| ----------------------------- | ---------------------------------------------------------------------------------- |
| macOS에서 "손상됨"이라고 나옴 | 위의 한 줄 명령으로 설치하거나 `xattr -cr /Applications/Chaya.app`                 |
| 콘솔이 인증을 요구함          | 터미널의 인증 링크로 엽니다. App은 자동으로 인증됩니다                             |
| 3927 포트를 이미 사용 중      | 다른 Chaya App / dev를 종료하고 다시 시작(App은 `PORT` 환경 변수로 포트 변경 가능) |
| Edge에서 폴더를 고를 수 없음  | Chrome / Edge로 바꿉니다                                                           |
