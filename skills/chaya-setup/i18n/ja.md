# Chaya：概要とインストール

Chaya は RPG Maker MV / MZ ゲーム向けのローカルツールキットです。ゲームライブラリの管理、NW.js シェルの導入、ゲーム内プラグイン（改造・高速化・翻訳）の注入、一括補完翻訳、ログ閲覧に加え、エージェントがゲームを直接操作できるローカル MCP を提供します。

## 3 つの形態

| 形態             | 内容                                   | できること                                                                           | できないこと                                                                               | 向いている人             |
| ---------------- | -------------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------ |
| **Edge**         | Web 版 `https://chaya-gray.vercel.app` | ブラウザでゲームフォルダーを許可してプラグインとシェルを書き込む、App のダウンロード | ゲームプロセスの起動、共有翻訳ライブラリ、ローカルモデル、完全な MCP（ゲーム内ツールのみ） | インストールせず試したい |
| **ローカル dev** | Node でソースを実行（`pnpm dev`）      | すべて：ライブラリ、ワンクリック起動、補完翻訳、翻訳ライブラリ、ログ、MCP            | —                                                                                          | 開発者、コードを変えたい |
| **App**          | デスクトップアプリ（macOS / Windows）  | ローカル dev と同じ。ダブルクリックで起動し、データはシステムのアプリフォルダー      | —                                                                                          | 普段使い（おすすめ）     |

選び方：普段のプレイと翻訳は **App**、エージェントにゲームを操作させるなら **App かローカル dev**、一時的にプラグインを入れたいだけなら **Edge**。

## App のインストール（おすすめ）

1. Chaya トップページのダウンロード欄で、Apple シリコン（M シリーズ）、Intel Mac、Windows x64 から選びます。おすすめは自動で表示されます。
2. **macOS は 1 行コマンドでのインストールがおすすめ**（「壊れているため開けません」が出ません）。ターミナルに貼り付けて Return：

   ```bash
   /bin/bash -c "$(curl -fsSL https://chaya-gray.vercel.app/sh/install.sh)"
   ```

3. macOS の手動インストール：zip を展開し `Chaya.app` を「アプリケーション」にドラッグ。「壊れている」と表示されたら `xattr -cr /Applications/Chaya.app` を実行してから開くか、App を右クリック →「開く」→「開く」。
4. Windows：zip を展開して `Chaya.exe` を実行。
5. App を起動するとコンソールウィンドウが開きます。アドレスは `http://127.0.0.1:3927` 固定です。

## ローカル dev のインストール

前提：Node ≥ 22.19、pnpm 9。

```bash
git clone https://github.com/DavidKk/chaya.git
cd chaya
pnpm i
pnpm dev          # ローカルモード、localhost:3000 で待ち受け
```

- `http://localhost:3000` を開けばすぐ使えます。ログインは不要です。
- そのほかの起動方法：`pnpm dev:lan`（LAN からアクセス可）、`pnpm dev:app`（Electron ウィンドウ付き、App と同じ）。Edge の動作を確認するには、`pnpm dev` の右上の dev スイッチャーで **Edge** を選びます。
- ゲーム内プラグインの変更は `pnpm dev` が自動で再ビルドし、ゲームはホットリロードされます。

## Edge の使い方

1. **Chrome か Edge** で `https://chaya-gray.vercel.app` を開きます（Safari / Firefox はフォルダー許可に非対応）。
2. ライブラリでローカルのゲームフォルダー（`www` か `index.html` を含む）を選び、読み書きを許可します。
3. ページがプラグインとシェルをゲームフォルダーに書き込みます。その後はローカルでダブルクリックして起動します（Web ページはプロセスを起動できません）。
4. 共有翻訳ライブラリ、ゲーム全体の補完翻訳などローカルディスクが必要な機能は Edge では使えません。App かローカル dev を使ってください。ゲームを開いている間は、エージェントはゲーム内 MCP ゲートウェイ `http://127.0.0.1:39271/mcp` でゲーム内ツールを使えます。

## 認証とセキュリティ

- ローカル dev と App にはログインがありません。API は localhost、IP アドレス、`CHAYA_PUBLIC_ORIGIN` からの同一オリジンのリクエストだけを受け付けます。Edge にもログインはありません。
- ゲームプラグインは起動ごとに生成される起動 token を使い、自分のゲームセッションにしかアクセスできません。

## よくある質問

| 問題                               | 対処                                                                                                    |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------- |
| macOS で「壊れている」と表示される | 上の 1 行コマンドでインストールするか、`xattr -cr /Applications/Chaya.app`                              |
| API が 401 を返す                  | `localhost` か IP アドレスでコンソールを開く。独自のホスト名なら `CHAYA_PUBLIC_ORIGIN` を設定して再起動 |
| 3927 / 3000 番ポートが使用中       | ほかの Chaya App / dev を終了して再起動（App は `PORT` 環境変数でポート変更も可）                       |
| MCP ポート 39271 が使用中          | ゲーム内「連携 → MCP」タブでポートを変更し、エージェント側のアドレスも更新                              |
| Edge でフォルダーを選べない        | Chrome / Edge に切り替える                                                                              |
