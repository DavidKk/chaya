# Edge MCP 需求

> 能力总表：[capabilities.md](./capabilities.md)（各环境的工具以它为准）

- **日期**：2026-10-04
- **状态**：已实现
- **适用**：Edge（Vercel 网页版）的「集成 → MCP」页
- **另见**：[插件 MCP](./mcp-plugin.md)、[本地 MCP](./mcp-local.md)

---

## 1. 是什么

Edge 没有服务端 MCP（Vercel 函数无长连接，触达不到用户本机的游戏）。Edge 的「集成 → MCP」整页是空态：说明网页版不支持 MCP，引导用户给游戏安装插件、打开游戏后在游戏内「MCP」页查看并接入。地址、端口、状态、工具都以游戏内为准（网页版不知道用户是否改过端口，写死默认地址反而误导），见 [mcp-plugin.md](./mcp-plugin.md)。

## 2. 页面内容

- 整页空态（`EmptyState`，水平垂直居中）：标题「网页版不支持 MCP，请在游戏中查看」，说明「给游戏安装插件并打开游戏后，在游戏内「集成」页查看并接入 Agent。」
- 无导航、无卡片、无按钮、无试调列，也无地址 / 端口 / 配置文件 / 安装方式。

- 不探测本机网关、不展示端口占用或服务是否开启（页面跨站访问本机端口会被浏览器私有网络限制拦截，也与网关拒绝跨站请求冲突）。
- Edge 的 WebMCP 页只描述 Edge 自身在浏览器内注册的工具。
