# Chaya: 게임 준비와 실행

## 준비

1. **local**(App / 로컬 개발): 라이브러리에서 `www`, 이를 포함하는 배포 폴더 또는 macOS `.app` / Windows `Game.exe` 패키지를 고릅니다. MV / MZ 콘텐츠 루트를 자동 감지합니다. 라이브러리 제거는 기록만 삭제합니다.
2. **cloud**: Chrome / Microsoft Edge에서 `www` 또는 `index.html` 폴더의 읽기 / 쓰기를 허용합니다.
3. 라이브러리 상세에서 공용 NW.js 셸(약 100 MB)을 설치합니다. 자체 셸이 있는 게임은 추가 설치가 필요 없습니다.
4. 플러그인을 설치하고 업데이트할 때마다 게임을 다시 시작합니다. 로컬 실행에서도 자동 주입합니다.

macOS 셸이 열리지 않으면 게임을 종료하고 터미널에서 실행한 뒤 안내에 따라 폴더를 고르고 `Chaya.app`을 엽니다. 저장 파일은 유지하고 이전 셸은 백업합니다:

```bash
/bin/bash -c "$(curl -fsSL https://chaya-gray.vercel.app/sh/mac-shell.sh)"
```

## 플러그인과 사용

`ChayaLoader`는 로딩과 오프라인 캐시, `ChayaLog`는 로그, `ChayaTrans`는 번역, `ChayaBoost`는 속도(`on()` / `off()`), `ChayaEdit`는 편집·이동·저장 / 불러오기(`help()`), `ChayaAgent`는 게임 제어를 담당합니다.

- **local**: 라이브러리에서 실행하면 세션 설정을 쓰고 게임을 엽니다. 플러그인은 로컬 서비스에 연결하고 콘솔이 온라인 상태를 표시합니다.
- **cloud**: 준비 후 게임 폴더 옆의 `Chaya.app` / `Chaya`를 엽니다. WebRTC로 통신하며 웹 페이지는 프로세스를 실행할 수 없습니다.
- 편집(`/cheat`): 돈, 아이템, 변수, 스위치, 캐릭터, 무적, 벽 통과, 속도, 이동, 저장 / 불러오기. 게임 단축키도 같은 패널을 엽니다.
- 번역(`/translate`): seed 추출 → 활성 엔진과 스케줄러 설정으로 전체 보완 작업을 시작하며 일시 정지할 수 있습니다. 캐시 조회·검색·편집·삭제·가져오기를 지원합니다. 게임 모드는 사전 번역, 실시간, 자막입니다. Cloud 작업은 연결된 게임이 실행하고 로컬 공유 라이브러리는 로컬 서비스가 필요합니다.
- 로그(`/logs`): 출처와 수준으로 오류를 찾습니다. 콘솔에서 종료하거나 창을 닫습니다. 대신 종료하거나 파괴적 편집, 플러그인 삭제, 저장 덮어쓰기, 불러오기를 하기 전에는 동의를 받습니다.

## 문제 해결

셸이 없으면 설치합니다. 플러그인이 무효하면 재설치·재시작하고 `ChayaLoader` 로그를 봅니다. 오프라인이면 `ChayaAgent` 로드와 연결 설정을 확인한 뒤 콘솔을 새로 고칩니다. macOS는 필요할 때 위 복구 명령을 사용합니다.
