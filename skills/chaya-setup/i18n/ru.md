# Chaya: установка и режимы

Chaya управляет играми RPG Maker, оболочкой NW.js, плагинами, изменениями, переводом, журналами и MCP.

## Выбор режима

- **local**: App (macOS / Windows) или локальная разработка. Полная библиотека, запуск, локальный перевод и MCP. Данные App хранятся в системной папке приложения.
- **cloud**: открыть `https://chaya-gray.vercel.app` в Chrome / Microsoft Edge, разрешить чтение и запись папки с `www` или `index.html`, установить плагины и оболочку. Игру запускать вручную. Веб-страница не запускает процессы и не предоставляет локальные модели или общую библиотеку локального сервиса.
- **plugin**: работает внутри открытой игры, в том числе без консоли. MCP предоставляет управление, редактирование, перевод, кеш, журналы и игровые знания; без управления библиотекой, запуска, batch и eval. В Cloud дополнение перевода выполняет `chaya_translate_job` подключённой игры.

## Установка App / среды разработки

В загрузках главной страницы выбрать Apple Silicon, Intel Mac или Windows x64. Установка через Терминал macOS:

```bash
/bin/bash -c "$(curl -fsSL https://chaya-gray.vercel.app/sh/install.sh)"
```

Либо распаковать и перенести `Chaya.app` в «Программы». При сообщении о повреждении выполнить `xattr -cr /Applications/Chaya.app` или правой кнопкой → Открыть → Открыть. В Windows распаковать и запустить `Chaya.exe`. Консоль App по умолчанию: `http://127.0.0.1:3927`.

Для разработки нужны Node ≥ 22.19 и pnpm 9:

```bash
git clone https://github.com/DavidKk/chaya.git
cd chaya
pnpm i
pnpm dev
```

Открыть `http://localhost:3000`. `pnpm dev:lan` разрешает LAN, `pnpm dev:app` включает Electron. Переключатель разработки: Local / Cloud. Изменения исходников пересобирают плагины.

## Доступ и неполадки

Вход в аккаунт не нужен. Локальный API принимает только запросы того же источника от localhost, IP или `CHAYA_PUBLIC_ORIGIN`. При 401 на собственном домене задать эту переменную и перезапустить. Токен плагина ограничен его сеансом; после обновления перезапустить игру. Если 3000 / 3927 заняты, закрыть другие экземпляры или задать `PORT` App.

MCP: `http://127.0.0.1:39271/mcp`. После смены порта в «Интеграция → MCP» внутри игры обновить клиент. При работающем local шлюз передаёт запросы локальному MCP. Для выбора папки Cloud нужны настольный Chrome / Microsoft Edge и разрешение; затем открыть `Chaya.app` / `Chaya` на компьютере.
