# services

单独服务：封装某种基础能力或三方/系统连接；可依赖配置与进程内状态。

| 目录         | 内容                                                       |
| ------------ | ---------------------------------------------------------- |
| `log/`       | 日志总线（内存环形缓冲 + 订阅 / SSE）                      |
| `game/`      | 配置持久化、绑定解析、装壳、Finder、插件检测               |
| `runtime/`   | 局内心跳 / 游戏在线、局域网 API 根注入                     |
| `translate/` | 翻译管线 CLI + 共享 SQLite 缓存（API 与 `pnpm translate`） |
| `extract/`   | 从游戏 `data/` 抽取可译字符串（`pnpm extract`）            |

未配置的类型与算法放 [`lib/`](../lib/)。
