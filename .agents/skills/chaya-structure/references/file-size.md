# 单文件行数与拆分

仅在改动将顶满 / 已超限、或需要选拆分策略时打开。

对齐工单服务「主要手写文件约 600–800 行」：

| 档         | 行数（手写源：`.ts` / `.tsx` / `.css` 等） | 动作                                 |
| ---------- | ------------------------------------------ | ------------------------------------ |
| 目标       | **≤ 600**                                  | 正常维护                             |
| 警告区     | **600–800**                                | 新增逻辑前优先拆分；勿继续堆叠       |
| **硬上限** | **> 800**                                  | **必须拆分**后再改功能；禁止只加不拆 |

## 怎么拆

1. 按职责切文件（采集 / 渲染 / 事件 / 类型 / API），同目录并列。
2. 模块变复杂 → **目录化 facade**：`foo.ts` 只重导出公开 API；实现放 `foo/*.ts`。
3. 私有细节默认紧邻调用方；行多再成夹；同类很多再收进 `components/` / `utils/`。
4. **不计入**：生成物（`plugins/dist`）、`node_modules`、锁文件、大体量 JSON 数据。
