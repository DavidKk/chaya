# Chaya：ゲームの準備と起動

## 準備

1. **local**（App / ローカル開発）：ライブラリで `www`、それを含む配布フォルダー、または macOS `.app` / Windows `Game.exe` のパッケージを選びます。MV / MZ の内容ルートを自動検出します。ライブラリからの削除は登録情報のみです。
2. **cloud**：Chrome / Microsoft Edge で `www` または `index.html` を含むフォルダーの読み書きを許可します。
3. ライブラリ詳細から共有 NW.js シェル（約 100 MB）を導入します。既にシェルがあるゲームには不要です。
4. プラグインを導入し、更新後は毎回ゲームを再起動します。ローカル起動時にも自動導入されます。

macOS のシェルが開かない場合、ゲームを終了してターミナルで実行し、案内に従ってフォルダーを選び、`Chaya.app` を開きます。セーブは保持され、旧シェルはバックアップされます：

```bash
/bin/bash -c "$(curl -fsSL https://chaya-gray.vercel.app/sh/mac-shell.sh)"
```

## プラグインと利用

`ChayaLoader` は読み込みとオフラインキャッシュ、`ChayaLog` はログ、`ChayaTrans` は翻訳、`ChayaBoost` は速度変更（`on()` / `off()`）、`ChayaEdit` は編集・移動・セーブ / ロード（`help()`）、`ChayaAgent` はゲーム制御を担当します。

- **local**：ライブラリで起動するとセッション設定を書き込み、ゲームを開きます。プラグインは本機サービスへ接続し、コンソールが接続状態を表示します。
- **cloud**：準備後、ゲームフォルダー横の `Chaya.app` / `Chaya` を開きます。通信は WebRTC、ブラウザーからのプロセス起動はできません。
- 編集（`/cheat`）：所持金、アイテム、変数、スイッチ、キャラクター、無敵、壁抜け、速度、移動、セーブ / ロード。ゲーム内ショートカットも同じ画面です。
- 翻訳（`/translate`）：seed 抽出 → 有効なエンジンとスケジューラーで全体補完。随時一時停止でき、キャッシュの参照・検索・編集・削除・取り込みに対応します。ゲーム内は事前翻訳・リアルタイム・字幕。Cloud のジョブは接続済みゲームが実行し、本機共有ライブラリにはローカルサービスが必要です。
- ログ（`/logs`）：発生元とレベルで障害を調べます。終了はコンソールまたはウィンドウから。代理終了、破壊的編集、プラグイン消去、セーブ上書き、ロードの前には同意を得ます。

## 問題解決

シェル不足なら導入、プラグイン無効なら再導入・再起動して `ChayaLoader` のログを確認します。オフラインなら `ChayaAgent` の読み込みと接続設定を確認し、コンソールを更新します。macOS は必要に応じて上の修復コマンドを使います。
