# 辅助：迷你面板管理需求

> 状态：已实现，更新于 2026-10-07。实现见 [技术文档](technical/mini-panels.md)。
> 日期：2026-10-07
> 关联：[`game-saves.md`](./game-saves.md) §6.3–6.4（存档迷你面板与快捷键）、[`input-assistance.md`](./input-assistance.md)（同属「辅助」）
> 技术方案：[`technical/mini-panels.md`](./technical/mini-panels.md)

## 1. 背景

游戏画面上已有四个迷你面板：迷你地图、旅伴、自动存档、快速存档。开关分散在三个页面（迷你地图、旅伴、游戏存档），游戏中要开关只能打开浮层逐个找，或者给每个面板单独绑快捷键。

新增一个很小的 **迷你面板管理**：游戏画面上一排图标，点一下开关对应的迷你面板，再点「关闭全部」一次收起所有面板。「辅助」新增二级页面 **迷你面板**，配置管理面板本身和其中显示哪些按钮。

### 1.1 术语

| 术语         | 含义                                                                      |
| ------------ | ------------------------------------------------------------------------- |
| 迷你面板     | 迷你地图、旅伴、自动存档、快速存档四个可拖动的游戏内小面板。              |
| 迷你面板管理 | 本需求新增的图标条，只用来开关迷你面板，本身不算在「迷你面板」里。        |
| 按钮项       | 管理面板里的一个图标按钮：四个迷你面板各一项，外加「关闭全部」，共 5 项。 |

## 2. 产品目标

| 目标 | 玩家可感知的结果                                         |
| ---- | -------------------------------------------------------- |
| G1   | 游戏中不打开浮层、不记快捷键，也能一键开关任一迷你面板。 |
| G2   | 一键收起全部迷你面板，画面马上干净。                     |
| G3   | 管理面板足够小，不遮挡游戏；横排或竖排按玩家习惯放。     |
| G4   | 管理面板里只出现玩家需要的按钮。                         |

## 3. 设置页面：辅助 › 迷你面板

- 「辅助」导航新增一项「迷你面板」，排在最后（旅伴 之后）。Web 控制台为 `/assist/panels`，游戏内浮层的「辅助」同样新增这一分区，两边是同一个页面。
- 页面从上到下两张卡片，样式与「游戏存档」页一致。

**卡片一：迷你面板管理**

- 标题行：标题「迷你面板管理」与说明「在游戏画面上显示一排图标，点击开关迷你面板」，右侧为「开启迷你面板管理」开关，默认关闭。切换成功后通知「已开启 / 已关闭迷你面板管理」。
- 设置区一行「排列方向」：左侧标题与说明「横向一行或纵向一列；也可以在管理面板上直接切换」，右侧下拉框「横向」/「纵向」，默认横向。

**卡片二：显示的按钮**

- 标题行：标题「显示的按钮」与说明「选择管理面板里出现哪些按钮」。
- 卡片标题与描述右侧一个总开关：打开即全部开启，关闭即全部关闭。5 项都开启时总开关为打开，都关闭时为关闭，部分开启时显示半开状态（滑块居中），点一下全部开启。
- 列表固定 5 行，顺序与管理面板里一致；每行左侧图标（与管理面板中相同）、名称、一句描述，右侧开关，默认全部开启：

| 按钮项   | 描述                                               |
| -------- | -------------------------------------------------- |
| 迷你地图 | 当前地图全貌与角色位置，只在地图场景显示           |
| 旅伴     | 与你同行的伙伴，陪你闲谈，也能替你打理游戏中的琐事 |
| 自动存档 | 自动存档列表，可立即存档、加载                     |
| 快速存档 | 10 个快速存档槽，可保存、读取                      |
| 关闭全部 | 一键关闭上面所有迷你面板，管理面板本身保留         |

- 这里的开关只决定按钮是否出现在管理面板里，不开关迷你面板本身；迷你面板的开关仍在各自页面，也可以用管理面板或快捷键开关。
- 设置与迷你地图、旅伴 的开关存在同一处（工具设置），所有游戏共用。只在 Chaya App 或本机服务中可用；不可用时两张卡片的开关、下拉框、按钮都禁用，并说明原因（与游戏存档页的「游戏内迷你面板」一致）。
- 读取工具设置前两张卡片显示骨架屏。

## 4. 游戏内的迷你面板管理

### 4.1 外观

- 一条很小的图标条，横向时一行、纵向时一列，粗细约 32 px，长度随按钮数变化。不能调整大小，没有标题栏、最小化、固定按钮。
- 从头到尾依次为：
  1. **拖动柄**：按住拖动整条，位置按游戏共用记住；
  2. **迷你面板按钮**：按卡片二开启的项，固定顺序迷你地图、旅伴、自动存档、快速存档；
  3. **关闭全部**：卡片二开启时显示，前面有一条细分隔线；
  4. **切换方向**：始终显示，前面有一条细分隔线。
- 全部是无边框的小图标按钮，悬停显示文字提示，不显示文字标签。提示在横向时显示在按钮下方，纵向时显示在按钮右侧（贴近右边缘时自动换到另一侧）。
- 迷你面板正在显示的按钮呈选中态（强调色底），并标记为按下状态，供读屏识别。
- 触屏设备上按钮放大到 44 px，与迷你面板标题栏按钮一致。
- 未悬停时半透明，鼠标移上或键盘聚焦时恢复不透明（迷你面板本身不再随悬停变化）。
- 卡片二的项全部关闭时，管理面板只剩拖动柄和切换方向按钮。

### 4.2 按钮行为

| 按钮     | 提示                                | 点击                                                                                                               |
| -------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 迷你面板 | 「显示迷你地图」/「隐藏迷你地图」等 | 与该面板的快捷键相同：正在显示则关闭它的开关；未显示（开关关闭，或本次被关闭按钮隐藏）则打开并显示。               |
| 关闭全部 | 「关闭全部迷你面板」                | 关闭四个迷你面板的开关，不确认。四个开关都已关闭时禁用（只被关闭按钮临时隐藏的面板仍算开启）。管理面板本身不关闭。 |
| 切换方向 | 「改为纵向排列」/「改为横向排列」   | 切换排列方向，与页面的「排列方向」是同一份设置。                                                                   |

- 开关与各页面、快捷键是同一份设置，任何一处改动后其他地方同步变化。
- 迷你地图只在地图场景显示，旅伴 在 Chaya 助手侧栏打开时隐藏；不在这些场景时按钮只切换开关，选中态按开关显示。
- 连续快速点击多个按钮时，每次点击都生效，不会互相覆盖。
- 设置保存失败时按钮状态保持保存前，管理面板照常显示，不另弹提示。

### 4.3 位置与显示范围

- 首次显示在游戏画面顶部居中。画面较宽时不与四个角上的迷你面板默认位置重叠；画面较窄（如 816 px 宽）时可能与右上角的迷你地图重叠，玩家拖开后记住位置。
- 拖动后记住位置，按与迷你面板相同的规则吸附：靠右边、下边时保持与该边的距离，否则按比例保持（默认居中）。切换方向或按钮项变化导致长度改变时保持这一锚点，超出画面时自动移回画面内。窗口缩放后同样保持在画面内。
- 只在游戏画面上显示，Web 控制台不显示。游戏内浮层打开时照常显示，层级与迷你面板相同，低于菜单、确认框和文字提示。
- 例外：旅伴面板挂在 Chaya 助手的独立图层上，层级高于作弊浮层，与管理面板重叠时会盖住管理面板及其提示；拖开即可。

### 4.4 开关与快捷键

- 开关在「辅助 › 迷你面板」卡片一，默认关闭。管理面板没有关闭按钮。
- 「辅助 › 快捷键」的「迷你面板」分组末尾新增「开关迷你面板管理」（管理面板本身不算迷你面板，但开关方式相同，放在同一分组），默认不绑定，规则与其他迷你面板快捷键相同（见 [`game-saves.md`](./game-saves.md) §6.4）。
- 工具设置不可用（不在 Chaya App 或本机服务中）时不显示管理面板，按键不拦截。一次保存失败或网络波动不算不可用。

## 5. 多语言

- 页面、提示、通知全部支持中文、英文、日文、韩文。日志保持中文。

## 6. 验收标准

1. 「辅助」导航最后一项为「迷你面板」，Web 与游戏内浮层都能打开，内容一致。
2. 默认管理面板关闭；打开开关后游戏画面顶部居中出现横向图标条，依次为拖动柄、4 个迷你面板按钮、分隔线、关闭全部、分隔线、切换方向。
3. 点击迷你地图按钮，迷你地图出现且按钮呈选中态；再点一次迷你地图关闭，页面「迷你地图」开关同步关闭。
4. 用迷你面板标题栏的关闭按钮隐藏某面板后，管理面板上该按钮变为未选中；再点一次面板重新显示。
5. 打开若干面板后点「关闭全部」，四个面板全部关闭，各页面开关全部变为关闭，管理面板仍在；四个开关都关闭时「关闭全部」禁用。用面板关闭按钮临时隐藏全部面板后，「关闭全部」仍可用，点击后开关全部关闭。
6. 快速连续点击迷你地图、自动存档、快速存档三个按钮，三个面板都打开。
7. 点击「切换方向」变为纵向一列，页面「排列方向」同步为纵向；刷新游戏后仍为纵向。
8. 在卡片二关闭「旅伴」，管理面板不再显示旅伴按钮，总开关变为关闭；打开总开关后 5 项恢复；再关闭总开关后只剩拖动柄和切换方向。
9. 拖动管理面板后重新进入游戏，位置不变；把窗口缩小，管理面板始终在画面内。
10. 所有按钮悬停都有文字提示，提示不被管理面板或作弊浮层内的迷你面板遮挡（旅伴面板例外，见 §4.3）。
11. 「快捷键 › 迷你面板」出现「开关迷你面板管理」，绑定后按下可显示 / 隐藏管理面板。
12. 非本机模式下页面控件禁用并说明原因，游戏画面不显示管理面板。
13. 切换为英文、日文、韩文后，页面与提示无中文残留。
